# 【689】操作日志优化

## 一、门店档案

### 1. 列表「操作日志」

1. 门店档案列表的查询区新增「操作日志」按钮，点击打开右侧抽屉，标题为「门店档案 · 操作日志」，查询全部门店档案的日志。
2. 抽屉与 UAT「所有主体 → 操作日志」样式一致：
   - 筛选：操作类型、操作结果（成功 / 失败），以及「查询」「重置」。
   - 列表：操作时间、操作内容、操作人、业务编号、结果、查看详情。业务编号显示门店名称，下方显示门店 ID；名称为空时只显示 ID。
   - 按操作时间倒序排列，每页 20 条，显示「共 X 条」、上一页、页码、下一页。没有数据时显示「暂无操作记录」。
3. 操作类型与 UAT 门店日志一致：创建门店、保存门店草稿、修改门店、提交门店、删除门店、修改提现手机号、进件提交、进件草稿、子主体独立进件。

### 2. 门店详情「操作日志」页签

门店详情新增「操作日志」页签，只查询当前门店的日志，与 UAT 门店详情一致：

- 筛选：操作类型、操作结果、时间范围、查询、重置。
- 列表：操作时间、操作内容、操作人、资源对象、方法、结果、查看详情。

### 3. 日志详情

点击「查看详情」打开居中弹窗（宽 760px）：

1. 顶部显示结果标签和操作内容。
2. 基础信息：操作时间、操作人、业务编号、操作结果。
3. 变更明细（共 N 项）：变更项、变更前（红色）、变更后（绿色）。一次保存产生的多项变更放在同一条日志里。新增类操作的变更前显示「—」，删除类操作的变更后显示「—」。
4. 失败记录显示失败原因，没有字段变更时显示「无字段级变更」。
5. 「技术信息」默认折叠，展开后显示后台动作标识、来源服务、请求方式、接口路径、客户端 IP、处理耗时、TraceID 和请求参数。请求参数中的手机号、验证码等敏感信息脱敏展示。

验收示例：张三修改门店「冷丰杭州总店」，详情显示操作人「张三」、操作内容「修改门店」，变更明细为「门店简称：冷丰杭州总店 → 杭州总店」。

## 二、暂不支持禁用

1. 门店档案、仓库档案的数据均为启用状态（门店显示「正常」，仓库显示「启用」）。
2. 门店档案列表操作列的「禁用」、仓库档案列表操作列的「停用」保留展示，但置灰、不可点击，鼠标悬停提示「暂不支持禁用」/「暂不支持停用」。
3. 列表的状态筛选项保持不变。

## 三、其他页面的操作日志

按 UAT 现有入口补齐以下页面。除另有说明外，抽屉、列表、详情与第一节一致，只查询所属模块；标题为「模块 · 操作日志」，单对象入口为「模块 · 操作日志 · 对象名称」。

| 页面 | 入口 | 抽屉标题 | 记录的操作类型 |
|---|---|---|---|
| 所有主体 | 列表上方「操作日志」 | 商家主体 · 操作日志 | 新增商家主体、调整商家状态 |
| 供应商档案 | 查询区「操作日志」 | 供应商 · 操作日志 | UAT 暂未配置操作类型，内容显示「其他操作」 |
| 仓库档案 | 查询区「操作日志」 | 组织仓 · 操作日志 | 新增仓库、修改仓库、调整仓库状态 |
| 选品库 | 工具栏「操作日志」 | 商品主档 · 操作日志 | 新增商品、修改商品、商品上架、商品下架 |
| 商品类目 | 页面右上「操作日志」 | 商品分类 · 操作日志 | 新增分类、修改分类、删除分类、调整分类显示 |
| 商城类目 | 工具栏「操作日志」 | 前台类目 · 操作日志 | 新增类目、修改类目、删除类目 |
| 直播场次 | 场次卡片菜单「操作日志」 | 直播场次 · 操作日志 · 场次名称（只查当前场次） | 新建直播场次、新建直播场次并绑定活动、编辑直播场次、删除直播场次、开始直播、结束直播、绑定活动、解绑活动 |
| 运费配置 | 工具栏「操作日志」 | 运费配置 · 操作日志 | 新增运费模板、修改运费模板、删除运费模板、同步运费模板；筛选区额外提供「模板名称 / ID」搜索，业务编号列名为「费用模板」 |
| 门店配置 | 「订单配置」区标题右侧「操作日志」 | 订单配置 · 操作日志 · 平台订单配置 | 保存平台订单配置、保存门店订单配置 |
| 推荐位配置 | 列表上方「操作日志」 | 推荐位列表 · 操作日志 | 新增推荐位、修改推荐位、删除推荐位、调整上下架状态 |
| 小程序协议 | 页面右上「操作日志」 | 协议配置 · 操作日志 | 保存协议 |
| 会员等级 | 查询区「操作日志」 | 会员等级政策 · 操作日志 | 发布会员等级政策 |
| 成长值规则 | 底部操作区「操作日志」 | 成长值规则 · 操作日志 | 保存成长值规则 |

说明：

1. 抽屉标题中的模块名与 UAT 保持一致（如仓库档案为「组织仓」、选品库为「商品主档」）。
2. 营销模版、优惠券、秒杀、红包及审核、积分规则、积分抵现、消费送积分、订单详情、结算策略管理已有操作日志，本需求不调整。
3. UAT 中直播配置、平台信息、APP 版本管理、组织 / 用户 / 角色 / 菜单 / 字典管理、消息模板管理也有操作日志，原型暂无对应页面，本次不涉及。
