# 【902】售卖范围门店查看

# 1. 后台业务 WEB 系统

## 1.1 概述

### 需求背景

配置门店售卖范围时，表单只显示已选数量。门店较多时，运营需要重新打开选择弹窗才能核对名单。本次在已选数量上增加查看入口，弹窗沿用直播场次的已选门店样式。

### 需求目标

在售卖范围为「门店」时，运营可直接点击已选数量，搜索并核对已选门店名单。

## 1.2 管理范围

| 模块 | 入口 |
| --- | --- |
| 商城商品、代采商品 | 商品列表 → 编辑商品 → 售卖范围 |
| 积分商城、新人专区 | 编辑积分商品、编辑新人专区商品 → 售卖范围 |
| 营销活动 | 秒杀活动 → 售卖范围 |
| 会员积分 | 积分抵现、消费送积分 → 售卖范围 |

## 1.3 交互规则

1. 范围类型为「门店」且已选至少一家门店时，显示可点击的「已选择 X 个门店」。打开已有配置时直接回显。新增或调整选择并确认后，数量和名单随当前表单更新，可在保存前查看。
2. 点击数量打开「已选门店（X个）」弹窗。列表显示门店名称，有地址时在名称下方展示地址。
3. 搜索范围为当前已选名单，支持按名称或地址搜索。搜索后回到第 1 页，标题中的 X 始终为全部已选数量，分页区显示匹配条数。无匹配时提示「没有匹配的门店」。
4. 列表每页 20 条，可点击页码、上一页或下一页切换。弹窗只读，可通过右上角关闭、底部「关闭」、点击遮罩或按 Esc 退出。需要增减门店时，从表单进入「选择门店」。
5. 范围类型切换为其他类型时隐藏门店查看入口。门店范围内清空选择后，已选数量入口消失。

## 1.4 验收标准

| 场景 | 预期 |
| --- | --- |
| 编辑已配置多家门店的商品 | 打开表单后直接点击数量，可核对已有名单 |
| 选择 28 家门店后确认 | 数量和弹窗标题显示 28 家，第一页 20 条，第二页 8 条 |
| 在第二页输入门店名称或地址 | 仅展示已选名单中匹配的门店，回到第一页，标题总数保持 28 |
| 关闭弹窗，再增减门店并确认 | 关闭操作保留当前选择，再打开时显示更新后的数量及名单 |
| 未选门店、清空选择或切换为其他范围类型 | 不显示可点击的门店数量 |
| 从各适用入口查看名单 | 标题、搜索、分页及关闭操作一致 |
