# 门店进件重复提示

## 目标与范围

门店负责人扫码注册、BD 添加或编辑门店提交资料，以及 ERP 管理后台编辑门店保存时，在原有必填项校验通过后，对门店名称、门店地址、联系电话进行重复提示。命中疑似门店时允许提交人核对并自主选择继续，原流程继续执行。

本提示用于发现疑似重复档案，不代替选址审核、手机号归属核验或支付机构进件校验。保存资料草稿时不弹窗。

## 交互

1. 门店／BD 点击「提交申请」「保存并提交」，ERP 后台点击编辑弹窗「确定」时，先执行现有必填项和材料校验。
2. 无疑似记录：按现有流程提交。
3. 有疑似记录：弹窗标题「发现疑似重复门店」，按命中字段的最高相似度降序，明细展示前 3 家；超过 3 家时，其余门店在下方以「、」连接成文案，并标明剩余数量。BD、PC 审核中心与 ERP 管理后台在汇总文案中使用「门店名称·门店编码」，门店 H5 仅展示门店名称。PC 审核中心明细中，门店编码与名称同行，命中依据在下一行。
4. 「返回修改」关闭弹窗并保留表单内容；门店／BD 点「确认，继续提交」执行原提交动作，ERP 点「确认，继续保存」执行原保存动作。弹窗本身不提前保存资料或创建进件单。
5. 编辑已有门店时排除当前门店自身；手机号仅以完整 11 位号码做精确匹配，已脱敏号码不参与该字段比对。
6. 门店在「门店注册」H5 点击「提交申请」，或在丰银宝 H5「商户进件」点击「提交审核」时，同样在原有必填项校验后执行疑似重复提示。点击「返回修改」保留当前表单；点击「确认，继续提交」才写入申请记录。App 内的疑似重复弹窗及蒙层限制在 App 页面容器内。
7. BD、BD 总监审核门店时，丰银宝 App 审核资料详情及 PC 审核中心详情／审核弹窗顶部展示「疑似重复门店」说明和命中字段，供审核人员核实。未命中不展示；提示不自动阻断审核。

## 原型匹配口径

原型以当前可读取的门店档案为候选。名称和地址去除空格、常见标点并转小写，使用编辑距离计算相似度。门店名称或地址相似度达到 60% 及以上时提示对应字段；手机号仅在双方均为完整 11 位手机号且号码完全相同（100%）时提示。任一字段命中即可出现疑似重复提示。地址由省市区与详细地址拼接。百分比为字段相似度，不是“同一家门店的概率”。这些阈值仅为原型演示值，上线前需用真实重复案例和误报案例校准，并明确跨端共用的数据源、查询时效及服务端防绕过策略。

## 验收场景

| 场景 | 预期 |
|---|---|
| 必填项缺失 | 沿用原错误提示，不出现重复弹窗 |
| 三字段均未命中 | 直接提交 |
| 仅名称、仅地址或仅手机号命中 | 弹窗标明实际命中字段和相似度 |
| 多字段命中 | 同一门店合并成一条，逐项展示相似度 |
| 多个疑似门店命中 | 按最高命中相似度排序，前 3 家逐条编号并展示明细；其余门店名称以「、」分隔汇总，标明剩余数量；弹窗和审核提示标明总数。App 弹窗的结果区域可独立滚动，标题与操作按钮保持可见 |
| 点击返回修改 | 不提交，输入内容保留 |
| 点击确认继续提交 | 仅提交一次，进入原审核流程 |
| 编辑当前门店 | 不与当前门店自身比较 |
| 已有手机号脱敏 | 不把星号号码当作相同手机号 |
| 门店 H5 命中 | 弹窗不展示门店编码；返回修改不提交，确认后只提交一次 |
| BD／总监查看命中申请 | 丰银宝 App 与 PC 审核详情顶部展示同一组疑似记录及命中依据 |
| 验收开关切换 | BD「添加门店」及门店注册 H5 提交页的 App 外侧展示，可选按资料匹配、模拟命中 5 家、模拟无命中；应用并刷新后更新演示状态。门店注册 H5 的预览弹窗不展示门店编号 |

## 原型边界

当前前端原型从内置样例、本会话门店列表或 ERP 门店档案表读取候选，只能演示交互；各端尚无真实跨门店查询接口。生产实现应由服务端在提交／保存时使用统一门店档案执行校验，以统一门店 ID 排除自身，返回候选的最少必要信息，并记录用户选择继续的结果。是否对完全相同手机号或地址设置强拦截，尚未确定；当前按“提示后可继续”处理。

界面预览入口：`/MDM/mdm_bd_store_form.html?previewDuplicate=1#new`。该入口显示固定示例，不提交资料；正常入口仍按表单输入和候选门店计算提示。

门店扫码页预览：`/MDM/mdm_bd_h5.html?previewDuplicate=1#register`；ERP 后台门店档案页预览：`/MDM/mdm_archive_store.html?previewDuplicate=1`，在列表点击「编辑」后出现示例提示。预览模式中的确认按钮不提交或保存。

BD 添加门店：`/MDM/mdm_bd_store_form.html#new`；门店注册 H5：`/shop-h5/h5/store/register.html`。这两页的验收开关位于 App 外侧，其余页面不展示。门店丰银宝 H5 进件：`/store-app/h5/onboarding.html?view=form`；丰银宝 BD 门店审核：`/MDM/mdm_bd_stores.html#audit/1`；PC 审核中心入驻审核：`/MDM/mdm_audit_store_registration.html`。模拟场景仅用于原型验收，不代表生产匹配结果。
