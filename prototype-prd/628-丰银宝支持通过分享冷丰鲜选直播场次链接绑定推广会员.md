# 【628】丰银宝支持通过分享冷丰鲜选直播场次链接绑定推广会员

来源清单：`merged-20260905-02`（大版本 `2026090401直播推广` 全部小版本 `.1`～`.5`）

# 1. 后台业务 WEB 系统

## 1.1 概述

### 需求背景

门店店长/员工只能用门店推广码拉新，无法把本店可看的冷丰鲜选直播场次直接分享到微信。BD 切到某门店后也不能看直播推广列表，分享无法带上当前所在门店和 BD 本人。用户点开链接或扫海报后，既没有携带门店和推广人参数，也不会在注册登录后自动绑到分享门店并进入该场直播；若先逛其他页再登录，参数更容易丢失。B 端会员「绑定门店」明细也看不到邀请人。本期按合并清单 `merged-20260905-02` 在丰银宝和 BD 工作台增加直播推广：店长/员工/BD 分享指定场次（海报或小程序卡片），链接携带当前门店和当前推广人账号；用户登录后绑定分享门店并进入该场直播，先逛后登录同样有效。分享门店停用时按用户已有门店关系分支处理（无绑定则绑默认店；已有可用当前店则保留；均不新增停用分享店会员关系），再以最终当前门店校验分发与观看权限；会员绑定记录展示邀请人。

### 需求目标

1. 丰银宝工作台「门店推广码」右侧增加「直播推广」，店长/员工均可进入本店可看场次列表。BD 切到某门店后也可从丰银宝工作台进入；左下角「直播推广验收开关」可切店长/员工或 BD 并选当前门店。
2. BD 工作台「进货」右侧增加「直播推广」，进入后身份为当前 BD，绑定门店为当前切到的门店，右上角可再切店。
3. 列表分直播中 / 未开始 / 已结束；仅官方全量、定向含当前门店、区域覆盖当前门店的已启用场次可见，草稿不展示。有直播中则默认进直播中（实际开播正序），否则默认未开始（计划开播正序）；已结束按实际开播倒序。已结束卡片不展示生成海报、分享直播。列表封面宽对齐后超出裁下方，高度不够则上下居中。页内展示当前门店和推广人。
4. 直播中、未开始可生成海报和分享直播。海报封面限定最大高度：宽对齐后不足则用实际高度，超出裁下方。分享直播为小程序卡片（品牌、包含分享门店名称的标题、5:4 封面、底栏「小程序」），封面宽对齐后超出裁下方、高度不够则上下居中。海报与链接均携带当前门店、当前推广人账号，目标为该场直播页。店长/员工带本店和店员账号；BD 带当前所在门店及 BD 姓名、手机号。
5. 列表上方展示推广路径（默认收起，点标题展开/收起）：店长/员工分享指定场次 → 扫 URL 码或打开链接 → 登录后校验场次 → 入会并切换自提 → 以最终门店校验权限后进原场次；分享门店停用时按用户关系回退/保留（见 1.3.6），不新增停用店会员。BD 入口保留不扩展。
6. 冷丰鲜选打开带参链接后前端一直缓存参数。未登录打开带参直播页先登录；也可先跳过或切到其他页面，稍后注册/登录仍继续原分享流程。已登录当场走主流程。海报/App 码为可解析 URL 二维码（非微信官方小程序码）。
7. 会员管理「绑定门店」明细在绑定方式后增加邀请人：姓名（手机号）；无则「—」。直播分享产生的记录绑定方式为「直播分享」，邀请人可为店员或 BD。

### 1.3.2 场次列表

#### 1.3.2.1 功能点：按状态查看本店可看场次

直播推广页展示当前门店可看场次。页内展示当前门店和推广人。三个 Tab：直播中、未开始、已结束。直播中/已结束展示实际开播时间，未开始展示计划开播时间。已结束不展示生成海报、分享直播。每条卡片左侧为直播封面图，按下列规则展示，三个 Tab 相同。BD 切到某店后，右上角可再切店，列表按该店可见范围刷新。

#### 1.3.2.2 功能流程图

```mermaid
flowchart TD

  C -->|无| E[默认 Tab 未开始]
```

需要说明的问题：

- 可见范围：官方全量可见；定向须包含当前门店；区域须覆盖当前门店。草稿不展示。

- **直播列表封面图展示规则**（与海报、分享卡片不同，只适用于列表左侧封面框）：
  1. 先把封面图按封面框**宽度对齐**（宽度撑满框，高度按原图比例缩放）。
  2. 宽对齐后，图的高度**高于**封面框：从顶部起展示，**裁剪下方**多出的部分，不裁左右、不居中裁上下。

  4. 宽对齐后高度刚好等于封面框：完整展示。
  5. 三个 Tab（直播中 / 未开始 / 已结束）同一套规则。

### 1.3.6 直播分享带参绑店

#### 1.3.6.1 功能点：带参进入冷丰鲜选后登录入会、切自提并进原分享场次

用户从丰银宝海报 URL 码、小程序卡片或 App 分享链接进入冷丰鲜选。链接携带门店、场次和当前账号。前端把参数写入本地缓存并持续保留。未登录先引导登录/注册（取消则不入会、不切店）；登录成功后避免默认选店或首页跳转覆盖分享目标。

主流程顺序：**先校验场次可用性**（已结束/已删除/失效/无权先拦截，暂不入会不切店）→ 处理门店会员关系与当前自提 → **以最终当前门店**复验分发范围与观看权限 → 通过则进入原分享场次；不通过则提示并进入该门店直播首页。未开始场次复用封面与「直播即将开始」。

门店会员关系与当前自提门店分离：多店并存；同店幂等且不重置首次绑定时间；新增分享门店关系不解除其他店关系；正常分享成功后直接切换自提为分享门店，无确认框。店员仅关联所属门店，不写店员业绩归属。本期新增范围以门店/店员为主；既有 BD 分享入口保留、不扩展。

分享门店停用分支（**仅直播分享入口**，不整体改其他扫码入口；**不得新增已停用分享门店的会员关系**）：

- 分享门店启用：入会分享门店并直接切自提，再进原场次。
- 分享门店停用且用户无任何门店绑定关系：绑定系统默认门店并设为当前自提，提示「分享门店已停业，已自动绑定默认门店」。
- 分享门店停用且用户已有正常可用的当前自提：保留原会员关系与当前店，提示「分享门店已停业，已保留当前门店」。
- 当前店不可用但有其他启用的绑定门店：复用现有可用门店选择规则；没有现成规则时引导选择，不擅自指定。
- 没有任何可用绑定门店：回退系统默认门店。
- 默认门店不可用：提示暂无法进入，不能继续绑定或反复回退。

码内容：原型采用可解析 **URL 二维码**（`live-share.html?ch=mp|app&…`），小程序入口与 App 扫一扫互通演示；**不是**微信官方小程序码。官方小程序码跨端识别为外部依赖。App 码微信扫→中间页引导浏览器打开；浏览器提供打开/下载；一次唤起失败不直接判未安装。安装后自动恢复为正式需求但依赖原生与国内应用市场，原型未完成；补救为返回浏览器再打开、或 App 内再扫原码。

### 1.3.8 BD 工作台 · 直播推广入口

#### 1.3.8.1 功能点：从 BD 工作台进入直播推广
