# 【903】PC-会员地址增删改

# 1. 后台业务 WEB 系统

## 1.1 概述

### 需求背景

会员详情的收货地址原先仅供查看。运营需要在会员详情中维护地址，并让会员在客户端看到更新后的地址簿。原列表中的「地址标签」（家 / 公司 / 父母等）无可靠数据来源，本期取消该类标签；「是否默认」仍需保留，且同一会员下仅允许一条默认收货地址，避免运营与客户端同时看到多个默认。

### 需求目标

1. 支持在 PC 端按会员新增、编辑和删除收货地址。
2. 列表与表单保留「是否默认」，取消「地址标签」展示与录入。
3. 同一会员全地址簿最多一条默认收货地址；设为默认时自动取消其它地址的默认。
4. 保存或确认删除后，客户端同一会员的地址簿同步更新（含默认标识）。

## 1.2 管理范围

| 终端 | 入口 | 变更内容 |
| --- | --- | --- |
| 后台 WEB | 会员 → 会员360 → 会员管理 → 会员详情 → 收货地址 | 展示地址列表，支持新增、编辑、删除；按单条地址展示并维护是否默认 |
| 客户端 | 我的 → 收货地址（地址簿） | 展示并维护当前会员地址；含默认地址的联系人卡片展示「默认」标识 |
| 客户端 | 切换地址、订单修改地址 | 使用当前会员最新可选收货地址，默认标识随单条地址数据同步 |

## 1.3 界面与交互规则

### 1.3.1 列表

1. 列：收件人信息、收件地址、收件人联系方式、是否默认、操作。每一行对应一条收货地址。
2. 「是否默认」为「是」时展示橙色「默认」标记；否则显示「否」。同一列表中最多一行显示「默认」。
3. 同一收件人下有多条地址时，也最多只有其中一条可为默认，不可同时出现多条「默认」。
4. 不展示家 / 公司 / 父母等地址标签列或文案。
5. 无地址时显示「暂无收货地址」。
6. 行操作：编辑、删除。

### 1.3.2 新增 / 编辑弹窗

1. 点击「新增收货地址」在页面可视区域中央打开独立弹窗，表单初始为空，「是否默认」默认不勾选。点击某行「编辑」打开「编辑收货地址」弹窗，回填该条地址及当前是否默认。
2. 弹窗沿用「规格管理」的白底圆角、标题栏、遮罩和按钮样式。收货地址与详细地址参考仓库地址的填写样式。
3. 表单字段：收件人、手机号码、收货地址（省市区）、详细地址、是否默认（勾选「设为默认地址」）。**不提供地址标签录入**。
4. 同一会员最多一条默认地址：勾选并保存后，其它地址的默认自动取消。取消勾选并保存后，本条地址不再为默认（不自动顺延到其它地址）。
5. 点击「保存」时校验表单。校验通过后关闭弹窗并刷新地址列表。点击「取消」、右上角关闭或按 Esc 退出，已保存地址保持原值。
6. 点击某行「删除」后弹出确认。确认后移除该条地址并刷新列表；若删空某联系人下全部地址，该联系人一并移除。取消删除时保留原记录。

## 1.4 数据要求

| 字段 | 是否必填 | 录入与校验规则 |
| --- | --- | --- |
| 收件人 | 是 | 文本输入，去除首尾空格后不能为空 |
| 手机号码 | 是 | 中国大陆 11 位手机号，正则为 `^1[3-9][0-9]{9}$`。格式错误时提示并阻止保存 |
| 收货地址 | 是 | 省、市、区三级联动，选完区县后回显完整地区 |
| 详细地址 | 是 | 多行文本，最多 200 字，实时显示字数。去除首尾空格后不能为空 |
| 是否默认 | 否 | 勾选表示设为该会员的默认收货地址；同一会员仅允许一条默认，读写时若出现多条则校正为仅保留一条 |

历史数据若仍带有「家 / 公司 / 父母」等地址标签，加载时忽略这些标签。若旧数据仅在联系人分组上标记默认，加载时迁到该组第一条地址，并保证全地址簿仅一条默认。

# 2. 客户端地址同步

## 2.1 同步规则

1. 后台维护的地址按会员 ID 关联。新增后客户端出现该地址，编辑后显示最新信息，删除后从可选地址中移除。
2. 默认标识与后台一致：含默认地址的联系人在地址簿卡片展示「默认」标记；订单改址等按地址行展示「默认」；非默认不展示该标记。
3. 客户端地址簿与后台会员详情共用地址数据。客户端保存的变更在后台重新打开该会员详情后可见。
4. 原型在同一浏览器、同一站点下共享地址数据。打开客户端地址簿进行验收时，应使用与后台操作对象相同的会员。

## 2.2 验收标准

| 场景 | 预期 |
| --- | --- |
| 打开会员详情收货地址 | 列表有「是否默认」列，无地址标签列；最多一行显示「默认」标记 |
| 同一收件人多条地址时设默认 | 仅被设为默认的那一行显示「默认」，同收件人其它行显示「否」 |
| 新增地址并勾选设为默认 | 保存后本条为默认，原默认自动取消；客户端同步显示「默认」 |
| 将另一条地址设为默认并保存 | 新默认显示「默认」，原默认变为「否」，列表始终只有一条默认 |
| 编辑取消「设为默认地址」 | 保存后本条不再为默认，列表显示「否」，不自动指定其它默认 |
| 点击新增和编辑 | 弹窗居中；新增为空表单，编辑正确回填；表单无地址标签，有是否默认勾选 |
| 选择省市区并填写详细地址 | 省、市、区依次联动，详细地址实时计数，最多 200 字 |
| 手机号为空、位数错误或号段格式不符 | 提示校验错误，无法保存 |
| 后台新增地址并保存 | 后台列表和同一会员客户端地址簿均出现新地址 |
| 后台编辑已有地址并保存 | 后台和客户端显示更新后的信息，同一地址仍为一条记录 |
| 关闭弹窗或取消删除 | 已保存的地址和客户端显示保持原值 |
| 后台确认删除 | 地址从后台列表和客户端可选地址中移除；删完最后一条显示空态 |
| 查看另一会员的地址 | 该会员仅显示自己的地址 |
