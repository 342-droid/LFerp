按订单渠道（零售、代采）和履约方式配置客户默认是否包邮。开关开启为包邮，关闭走TMS 物流费率表计费。零售自提、零售快递默认包邮且不可变更；代采配送、代采快递可开关。关闭后快递与配送一样，按重量 / 订单金额 / 件数计费。商城 / 代采 / 直播编辑商品时可单独覆盖。
零售
开启（不可变更）
适用商城、直播到店自提。固定包邮，不可关闭。
开启（不可变更）
适用商城、直播快递到家。固定包邮，不可关闭。
代采
关闭
适用代采仓配到店。关闭则按门店对应配送仓 → 门店地址计费。
开启
适用代采快递到店。关闭则按供应商发货地 → 门店地址计费，计费方式与配送相同（按件 / 按重量 / 按订单金额）。
