## 1. 需求描述

### 1.1 审核中心新增 RBT审核

顶部导航「审核中心」下，侧栏新增一级菜单「RBT审核」，其下二级菜单「需求单审核」。

原型页面：`MDM/mdm_audit_rbt_demand.html`

与「需求单管理」（RBT 模块）共用需求数据：门店端发布成功后，需求单管理出现「待审核」单据，同时本页新增一条初审记录。需求进入「待复核」后，本页再新增一条复核待审核。

### 1.2 逻辑说明

#### 1.2.1 产生审核记录

* 触发：门店端发布需求成功
* 效果：
  * RBT「需求单管理」新增状态为「待审核」的需求单
  * 审核中心「需求单审核」新增一条「初审」、状态为「待审核」的审核单
* 历史已有需求单在进入本页时按状态补齐审核记录（演示同步）

#### 1.2.1b 复核审核

* 触发：需求单状态变为「待复核」（三份合同全部签署完成）
* 效果：同一需求单再新增一条「复核」、状态为「待审核」的审核单；原来的初审记录保持「审核通过」
* 已处于「待复核」的历史单据，进入本页时补一条复核待审核

#### 1.2.1a 需求单管理快捷入口

* RBT「需求单管理」操作列固定显示「审核」，仅「待审核」「待复核」可点，其余状态置灰
* 点击后跳转本页，并按该行需求单号自动带入查询条件；审核状态不默认带值

#### 1.2.2 查询

* 需求单号（可兼匹配审核单号）
* 门店（名称或编码，包含匹配）
* 审核状态：全部 / 待审核 / 审核通过 / 审核驳回

支持查询、重置；分页默认每页 20 条。

#### 1.2.3 列表字段

* 审核单号
* 需求单号
* 审核环节：初审 / 复核
* 门店（名称 + 编码）
* 商品包
* 商品金额、服务费、总金额
* 提交人
* 提交时间
* 审核状态
* 审核人
* 审核时间
* 操作：详情；待审核时另有「通过」「驳回」

#### 1.2.4 审核操作

**通过（初审）**

* 仅「初审」且「待审核」可操作，弹出本单的结算比例维护。结算比例只在这里按当前需求单维护，维护结果记在这张需求单上，每张需求单各自一份
* 渠道固定为 POS、直播、商城。每个渠道必须填写默认比例
* 商品类目从下拉中选择后填写比例并添加，选项与选品库商品类目一致。同一渠道同一类目只加一条。未添加的类目使用该渠道默认比例
* 比例大于 0 且不超过 100，保留两位小数
* 确认后：该审核单 → 审核通过；关联需求单状态 → **待接单**；本单结算比例记到该需求单
* 需求单列表、详情和合同在记入后展示这份比例。发布时不写结算比例；还没维护的列表和详情为「—」，门店端和贸易商端卡片不展示这一行。待接单到支付中，需求单管理可再改这份比例，不改需求状态
* 不释放占用额度

**通过（复核）**

* 仅「复核」且「待审核」可操作，弹出复核核对
* 核对并提醒三项：
  1. 对应合同是否全部签署完成。按各合同当前签署状态实时查询并展示；未全部签署不能通过
  2. 需求门店担保金是否缴纳。选择「未缴纳」或未选择不能通过
  3. 上传需求门店的担保金缴纳凭证（图片或 PDF）。未上传不能通过
* 合同已全部签署、担保金已缴纳且已上传凭证后：该审核单 → 审核通过；关联需求单状态 → **支付中**；凭证保存在需求单上；同时生成冷丰销售单、贸易商销售单、供应链采购单、门店采购单。门店向贸易商的采购单同步下发 WMS 采购入库单（关联单号=需求单号；不允许差异收货，只允许全量收货；完结后回写该 PO 和对应贸易商 SO 为已完成），见《销售单PRD》《采购单PRD》
* 不释放占用额度。需求门店已成交按《门店管理PRD》在进入支付中时增加

**驳回**

* 仅「待审核」可操作。复核在同一核对弹窗中填写驳回原因；初审沿用原因填写
* 须填写驳回原因
* 确认后：当前这条审核单 → 审核驳回；关联需求单状态 → **已驳回**
* 释放该需求对需求门店的已占用额度

**详情**

* 打开关联需求单详情（与需求单管理详情一致）
* 复核通过并上传凭证后，详情「担保金缴纳凭证」可查看缴纳状态、文件、上传人和凭证内容

#### 1.2.5 状态联动

| 来源 | 审核环节 | 审核单状态 |
| --- | --- | --- |
| 门店刚发布 / 需求仍为待审核 | 初审 | 待审核 |
| 初审通过并维护本单结算比例 / 需求已进入待接单、待签署 | 初审 | 审核通过 |
| 需求变为待复核 | 复核（新单） | 待审核 |
| 复核通过 / 需求进入支付中、已完成 | 复核 | 审核通过 |
| 本页驳回 / 需求为已驳回 | 当时待审核的那一条 | 审核驳回 |
| 门店取消（仅待审核） | 初审仍待审核的那一条 | 审核驳回，意见「需求已作废」 |
| 平台作废需求 | 仍待审核的初审或复核 | 审核驳回，意见「需求已作废」 |
| 平台作废需求 | 已经审核通过的初审或复核 | 保持审核通过 |

## 2. 菜单结构

审核中心侧栏（自上而下）：

* 审核中心：入驻审核、进件审核
* 营销审核：优惠券、现金红包、派发红包
* **RBT审核：需求单审核**
