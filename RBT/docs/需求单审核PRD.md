## 1. 需求描述

### 1.1 审核中心新增 RBT审核

顶部导航「审核中心」下，侧栏新增一级菜单「RBT审核」，其下二级菜单「需求单审核」。

原型页面：`MDM/mdm_audit_rbt_demand.html`

与「需求单管理」（RBT 模块）共用需求数据：门店端发布成功后，需求单管理出现「待审核」单据，同时本页新增一条审核记录。

### 1.2 逻辑说明

#### 1.2.1 产生审核记录

* 触发：门店端发布需求成功
* 效果：
  * RBT「需求单管理」新增状态为「待审核」的需求单
  * 审核中心「需求单审核」新增状态为「待审核」的审核单（一对一关联需求单号）
* 历史已有需求单在进入本页时按状态补齐审核记录（演示同步）

#### 1.2.1a 需求单管理快捷入口

* RBT「需求单管理」操作列提供「去审核」，仅「待审核」「待复核」状态展示
* 点击后跳转本页，并按该行需求单号自动带入查询条件；审核状态不默认带值

#### 1.2.2 查询

* 需求单号（可兼匹配审核单号）
* 门店（名称或编码，包含匹配）
* 审核状态：全部 / 待审核 / 审核通过 / 审核驳回 / 已取消

支持查询、重置；分页默认每页 20 条。

#### 1.2.3 列表字段

* 审核单号
* 需求单号
* 门店（名称 + 编码）
* 商品包
* 货款总金额
* 提交人
* 提交时间
* 审核状态
* 审核人
* 审核时间
* 操作：详情；待审核时另有「通过」「驳回」

#### 1.2.4 审核操作

**通过**

* 仅「待审核」可操作
* 确认后：审核单 → 审核通过；关联需求单状态 → **待接单**
* 不释放占用额度

**驳回**

* 仅「待审核」可操作
* 须填写驳回原因
* 确认后：审核单 → 审核驳回；关联需求单状态 → **已驳回**
* 释放该需求对需求门店与担保门店的已占用额度

**详情**

* 打开关联需求单详情（与需求单管理详情一致）

#### 1.2.5 状态联动

| 来源 | 审核单状态 |
| --- | --- |
| 门店刚发布 / 需求仍为待审核 | 待审核 |
| 本页通过 / 需求已进入待接单及之后主链路 | 审核通过 |
| 本页驳回 / 需求为已驳回 | 审核驳回 |
| 门店取消需求（仅待审核、待接单可取消） | 已取消 |

## 2. 菜单结构

审核中心侧栏（自上而下）：

* 审核中心：入驻审核、进件审核
* 营销审核：优惠券、现金红包、派发红包
* **RBT审核：需求单审核**
