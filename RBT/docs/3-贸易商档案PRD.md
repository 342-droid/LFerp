## 1. 需求描述

贸易商由业务伙伴下的商家主体准入，并在商家列表中用贸易商档案承接。交互对齐现有供应商：先在所有主体建商家，再在档案里补资料、查询和进件。

服务商单独建档，见《服务商档案PRD》。贸易商只绑定服务商名称，不在本档维护服务商类型。

### 1.1 入口

顶部进入「业务伙伴」。

- 商家主体 / 所有主体：新增按钮最下方增加「新增贸易商商家」，排在「新增仓库商家」之后、「新增服务商商家」之前。
- 商家列表：增加「贸易商档案」，排在「仓库档案」之后、「服务商档案」之前。

原型页面：

- 所有主体：`MDM/mdm_party_all.html`
- 贸易商档案：`MDM/mdm_archive_trader.html`

## 2. 所有主体

列表是门店、供应商、仓库、贸易商、服务商的合并列表。查询条件不变：商家名称、商家状态。商家类型包含「贸易商」。

### 2.1 新增贸易商商家

点击「新增贸易商商家」，打开「添加贸易商商家」。两步抽屉，先主体、再贸易商。需要短信验证码，不收集登录账号，不选择绑定 BD。页顶提示：所填信息为合同签约的控件填充字段，请谨慎填写。

第一步「主体信息」：

- 主体名称：必填
- 主体类型：必填，不可编辑，固定显示「贸易商」
- 联系人：必填
- 手机号码：必填，11 位，旁有「获取验证码」
- 验证码：必填，6 位数字
- 证照与结算：与结算信息合在这一步，不单独拆步。包含营业执照（照片、商户名称、证照编号、证照有效期、成立日期、省市区、详细地址）、法人身份证（人像面、国徽面、法人姓名、证件号码、证件有效期、省市区、详细地址）、法人实名电话、结算信息（开户许可证、开户名、银行卡号、开户银行、开户支行）

第二步「贸易商信息」：

- 贸易商名称：必填
- 贸易商简称：可不填。空着时保存后取名称前 6 个字
- 贸易商状态：必填，正常、冻结，默认正常
- 绑定服务商：必填。服务商档案里有「冷丰」时默认选中，可改。下拉只含服务商档案中的服务商名称
- 贸易商地址：必填，省 / 市 / 区
- 详细地址：必填，最多 200 字。下方有地图定位示意，不单独落库

第一步底部为「取消」「下一步」，第二步为「取消」「上一步」「提交」。未完成的步骤不能直接点过去。当前步必填未填时停在本步。主体字段提示：请输入主体名称、请输入联系人、请输入手机号码、请输入11位手机号码、请输入6位数字验证码。贸易商字段提示：请输入贸易商名称、请选择绑定服务商、请输入贸易商地址、请输入详细地址。证照与结算未上传或未填时提示「请上传…」「请填写…」。

保存成功后不跳转档案页，提示「已提交入驻审核，审核全部通过后发起合同签署」。审核仍在审核中心，本页只发起。

审核全部通过后发起合同签署，当前合同模板未确认，不一定会进行线上签署，暂跳过

同时：

- 所有主体新增一行。商家 ID 前缀 `TRD`，商家类型为「贸易商」，绑定 BD、登录账号展示「—」，状态为「开启」，最后操作人为当前用户。手机号按前 3 后 4 脱敏。

列表中贸易商的禁用确认文案为「确定禁用此贸易商吗？」。开启、禁用规则与其他商家相同。

## 3. 贸易商档案

面包屑：业务伙伴 / 资源中心 / 贸易商档案。

贸易商入驻审核通过后，产生贸易商档案数据。

### 3.1 查询

条件按以下顺序。可只填一部分。文本为包含匹配；下拉为精确匹配。

- 绑定服务商：按名称包含匹配
- 联系人姓名
- 联系人手机号：可按展示的脱敏号码匹配，也可只输入其中连续数字
- 贸易商名称
- 进件状态：全部、未进件、进件中、进件成功、进件失败
- 贸易商状态：全部、正常、冻结

「查询」按当前条件刷新。「重置」清空以上条件并恢复全部记录。

### 3.2 列表

列顺序：

- 贸易商名称：可点击，当前页打开详情，地址不变
- 贸易商简称
- 贸易商地址
- 贸易商详细地址
- 绑定服务商：展示已绑定的服务商名称。没有时按「冷丰」
- 联系人姓名
- 手机号码
- 进件渠道：本期演示固定为「汇付」
- 进件状态
- 余额支付：演示数据为「已开通」「未发起」
- 贸易商状态：正常、冻结
- 创建人
- 创建时间
- 更新人
- 更新时间
- 操作：编辑、去进件

主体名称、贸易商名称、简称、地址、详细地址过长时左对齐并省略，悬停可看全文。空值展示「—」。分页默认每页 10 条，与其他档案列表一致。

查询区按钮：重置、查询。档案页不提供「新增贸易商」，贸易商从所有主体准入后写入。

### 3.3 编辑

档案页不提供「新增贸易商」。列表「编辑」打开「编辑贸易商」，两步抽屉。地址在第一步，证照与结算合在第二步。地址下方有地图定位示意，不单独落库。不出现经营许可证、牌照类型、业务范围。

第一步「贸易商信息」：

- 主体名称：必填，从已有贸易商档案的主体名称中选择。当前主体不在选项里时，补进下拉并选中
- 主体类型：必填，不可编辑，固定显示「贸易商」
- 贸易商名称：必填
- 贸易商简称：可不填
- 绑定服务商：必填。下拉只含服务商档案中的服务商名称，同名只出现一次
- 贸易商状态：必填，正常、冻结，默认正常
- 联系人姓名：必填
- 手机号码：必填，带「获取验证码」。已脱敏号码（含 `*`）保存时不再校验 11 位；未脱敏时必须是 11 位
- 验证码：必填，6 位数字
- 贸易商地址：必填，省 / 市 / 区
- 详细地址：必填，最多 200 字

第二步「证照与结算」：营业执照、法人身份证、法人实名电话、结算信息合在这一步。字段与所有主体新增第一步的证照与结算相同。

第一步底部为「取消」「下一步」，第二步为「取消」「上一步」「提交」。当前步未完成不能进入下一步。必填未填时提示对应字段：请选择主体名称、请输入贸易商名称、请选择绑定服务商、请输入贸易商地址、请输入详细地址、请输入手机号码、请输入验证码、请输入联系人姓名。手机号、验证码格式不对时分别提示「请输入11位手机号码」「请输入6位数字验证码」。证照与结算未上传或未填时提示「请上传…」「请填写…」。

保存成功后关闭抽屉并刷新列表。编辑更新联系人、地址、绑定服务商、状态、证照与结算等已改字段，并刷新更新人、更新时间；不改写进件状态、进件渠道。进件未成功时余额支付仍为「未发起」，进件成功后为「已开通」。

### 3.4 详情

点击贸易商名称打开「贸易商详情」。页头展示简称，没有简称时用贸易商名称；标签带出贸易商状态和进件状态。页签为「基础信息」「进件信息」。

基础信息：

- 贸易商名称、贸易商简称
- 贸易商地址、贸易商详细地址、绑定服务商
- 联系人姓名、手机号码
- 进件渠道、进件状态、余额支付、贸易商状态
- 创建人、创建时间、更新人、更新时间

基础信息下方另有「证照与结算」：回显已保存的营业执照、法人身份证、法人实名电话和结算信息。没有保存过时展示「未填写」。不展示经营许可证、牌照类型、业务范围。

进件信息对齐供应商档案：展示已保存的进件资料、进件记录，以及「去进件」「绑定商户号」。无论是否已有商户号，都可以再次去进件或绑定商户号。进件审核仍在审核中心，审核流程对齐供应商档案，本页只发起和保存。

### 3.5 去进件

列表操作「去进件」与详情进件信息里的「去进件」打开同一套「贸易商进件」。同一贸易商共用一条进件记录。

带入：贸易商简称，无简称时用贸易商名称；详细地址；手机号码。

提交后列表和详情的进件状态改为「进件中」。删除或清空进件记录后回到「未进件」。进件结果为成功或失败时，列表标签与档案中的进件状态一起更新。
