## 1. 需求描述

### 1.1 RBT 下新增需求单管理

进入 RBT 后，左侧菜单顺序为「首页」「门店管理」「商品包」「产品配置」「需求单管理」「采购单」「销售单」；「需求单管理」在「产品配置」下方。贸易商在业务伙伴的贸易商档案维护。

原型页面：`RBT/rbt_demand.html`

本页为 B 端需求单全量台账：展示门店端（丰银宝 / RBT-移动端门店菜单）发布的需求，支持查询、详情查看，并在「待审核」「待复核」时快捷跳转审核中心。审核通过 / 驳回在「审核中心 → RBT审核 → 需求单审核」完成，本页不直接做审核操作。

数据与门店端发布、审核中心、门店额度共用。

### 1.2 逻辑说明

#### 1.2.1 查询

查询条件按以下顺序展示。需求单号、门店、商品包、贸易商、服务商为包含匹配，不区分大小写；状态为精确匹配。条件可只填一部分。

* 需求单号
* 门店：匹配门店名称或门店编码
* 商品包：匹配商品包名称或商品包编码
* 贸易商：匹配接单贸易商名称
* 服务商：匹配服务商名称或服务商编码
* 状态：下拉，选项含主链路与旁路全部状态（见 1.2.3）

* 「查询」按当前条件刷新，并回到第 1 页
* 「重置」清空条件，恢复全部记录
* 分页默认每页 20 条
* 切回本页或窗口重新获得焦点时刷新列表（便于看到门店端发布、审核中心操作后的最新状态）

#### 1.2.2 列表

操作列固定在右侧。

* 需求单号：可点击，在当前页打开详情抽屉，地址不变
* 门店
* 商品包
* 贸易商：接单贸易商。未接单时为「—」
* 服务商：初审确认有服务商时显示名称。未指定时为「—」
* 接单时间：未接单时为「—」
* 商品金额：所选商品售价合计，`¥` + 金额
* 服务费：总金额 − 商品金额，`¥` + 金额
* 总金额：原货款总金额，占用额度和已成交按此金额，`¥` + 金额
* 贸易商应收、冷丰应收、服务商应收：紧跟总金额。按本单产品配置的结算系数和商品金额计算。贸易商应收 = 商品金额 × 贸易商结算系数；冷丰差额 = 商品金额 × 门店结算系数 − 贸易商应收；服务商应收 = 商品金额 ×（服务商结算系数 − 1），从冷丰差额里拿；冷丰应收 = 冷丰差额 − 服务商应收。待审核、以及还没确认过是否有服务商的已驳回、已作废，按产品配置计提服务商。初审通过后：确认有服务商才计提；确认没有时服务商应收为 0，这笔改记入冷丰应收。算不出时为「—」
* 结算周期
* 结算方式：比例付
* 结算比例：有结算比例时显示「详情」，点击弹出结算比例详情；待接单到支付中另有「改比例」，点击弹出与初审通过相同的维护框，保存后覆盖本单结算比例，不改需求状态。没有结算比例且不可改时为「—」
* 状态：标签展示
* 创建人
* 创建时间
* 更新人
* 更新时间
* 操作：每行固定显示「审核」「签署」「作废」，不满足条件时置灰。待审核、待复核可点「审核」；待签署可点「签署」，点击在当前页弹出合同签署，不跳转其他页面；支付中之前（待审核、待接单、待确认签约、待签署、待复核）可点「作废」，确认后需求变为「已作废」并释放占用额度。已经生成的销售合同、采购合同签署状态变为「已作废」，不能再签署；还没生成合同的，详情仍是空态。已经审核通过的审核单保持不变；仍待审核的按驳回处理，驳回意见为「需求已作废」。支付中、已完成、已作废、已驳回「作废」置灰

无数据时展示空列表。

#### 1.2.3 需求状态

主链路：

待审核 → 待接单 → 待确认签约 → 待签署 → 待复核 → 支付中 → 已完成

旁路：

* 已作废：门店仅在待审核取消，或平台在支付中之前作废
* 已驳回：审核中心驳回

说明：

* 门店端发布成功后初始状态为「待审核」
* 审核中心初审「通过」后：需求状态变为「待接单」；本单按渠道维护的结算比例记在需求单上。列表有结算比例时显示「详情」，点击弹出结算比例详情；待接单到支付中在结算比例列显示「改比例」，保存后覆盖本单记录。没有结算比例且不可改时为「—」。需求单详情和该弹窗用同一张表：渠道、默认比例、商品类目、类目结算比例；同一渠道有多个类目时占多行，渠道之间的类目可以不同。合同按渠道写出该渠道自己的默认比例和商品类目。发布时不写结算比例，还没初审通过的显示「—」。已经初审通过、单上还没有这份比例的历史单，按当时产品上的比例作为三个渠道的默认比例展示
* 贸易商端需求大厅分「待接单」「已接单」两个页签，可切换。每个页签上用数字标出该页签下的需求条数。只有主体类型为「贸易商」的账号能看见数据：待接单展示全部尚未被接的需求；已接单只展示当前登录贸易商接过的需求，并显示接单后的需求状态与接单时间。主体类型为「服务商」的账号两个页签都没有数据，也不能接单。发布需求的门店只看自己发布的需求。贸易商接单后：状态变为「待确认签约」，写入接单贸易商与接单时间，此时不生成合同；一笔需求单只允许一个贸易商接单。待确认签约可「确认签约」或「撤回接单」：确认后进入「待签署」并生成销售合同、采购合同；撤回后清空接单贸易商，需求回到「待接单」。待签署展示「去签署」
* 审核中心「驳回」后：需求状态变为「已驳回」，并释放占用额度
* 待签署及之后可有关联合同。已作废时：作废前已生成的合同保留，签署状态为「已作废」；作废前未生成合同的仍为空态。已驳回无合同
* 待签署展示两份合同，由对应双方分别确认；全部签完后需求状态变为「待复核」，并在审核中心新增一条「复核」待审核。销售合同：需求门店与接单贸易商。采购合同：接单贸易商与冷丰供应链。冷丰供应链在本页弹窗确认采购合同，不代门店或贸易商签署
* 审核中心复核「通过」后：需求状态变为「支付中」，并生成冷丰销售单、贸易商销售单、供应链采购单、门店采购单。冷丰销售和供应链采购用商品原始售价；门店采购的商品售价 = 原始售价 × 门店结算系数；贸易商销售的商品售价 = 原始售价 × 贸易商结算系数。门店向贸易商的采购单生成后，同步下发 WMS 采购入库单：关联单号=需求单号；不允许差异收货，只允许全量收货；入库完结后该门店采购单和对应贸易商销售单改为已完成。规则见《需求复核后单据方案》方案一、《销售单PRD》《采购单PRD》。通过前按实时签署状态核对合同是否全部签署，并确认担保金已缴纳、上传缴纳凭证
* 历史状态迁移（演示兼容）：已发布 / 待报价 → 待审核；已报价 → 待接单；待还款 → 支付中

#### 1.2.4 审核

* 展示条件：状态为「待审核」或「待复核」
* 点击后跳转：`审核中心 / RBT审核 / 需求单审核`
* 自动带入查询条件：需求单号 = 当前行单号
* **审核状态不默认带值**（查询区审核状态保持「全部」）
* 本页不在操作列提供通过 / 驳回；审核动作见《需求单审核PRD》

#### 1.2.5 详情

点击需求单号，右侧抽屉打开「需求单详情」。页签两个：基础信息、操作记录。基础信息页签包含下面内容：

**门店额度**

* 当前需求门店的：门店总额度、已占用、可用额度（口径同门店管理：可用 = 总额度 − 已占用）

**基础信息**

* 需求单号、状态
* 接单贸易商、接单时间：未接单时为「—」
* 服务商：初审通过时先确认是否有服务商。选「是」后从贸易商档案中主体类型为服务商的档案里指定；选「否」或未指定时为「—」
* 门店（名称 + 编码）
* 商品包（名称 + 编码）
* 产品（名称 + 编码）
* 结算周期、结算方式
* 结算比例：详情单独一块，用表格展示。列是渠道、默认比例、商品类目、类目结算比例。同一渠道多个类目占多行。每个渠道先列自己单独维护的类目；本单商品类目这个渠道没单独填时，按该渠道默认比例补一行。渠道之间的类目可以不同。还没初审通过的不展示这张表。待接单到支付中，标题旁有「修改结算比例」
* 创建人、创建时间、更新人、更新时间

**金额信息**

基础信息下方单独一块，表格样式与商品明细相同。一行六列：商品金额、服务费、总金额、贸易商应收、冷丰应收、服务商应收。总金额为原货款总金额，服务费 = 总金额 − 商品金额。三方应收口径与列表相同。

**商品明细**

表格列：商品编码、商品名称、售价、数量。无商品时表格空态。

**关联合同**

* 需求状态为「待签署」「待复核」「支付中」「已完成」时展示合同。已作废且作废前已生成合同时，仍展示这些合同，签署状态为「已作废」。其余状态（含待审核、待接单、待确认签约、未生成合同的已作废、已驳回）展示空态「暂无关联合同」
* 有值时列出：销售合同、采购合同。每份展示编号、双方签署方和该份文件的签署状态
  * 一份协议的双方都已确认时，该协议为「已签署」；否则为「待签署」
* 协议名称可点击预览正文（弹层预览，含双方与关联需求要素摘要）

**担保金缴纳凭证**

* 复核通过时上传的需求门店担保金缴纳凭证保存在需求单上，详情可查看
* 尚未上传时展示空态「暂无担保金缴纳凭证」
* 已上传时展示缴纳状态、凭证文件名、上传人、上传时间；图片可直接查看，PDF 可打开查看

**关联购销单**

* 需求为「支付中」「已完成」时展示。列出冷丰销售、供应链采购、贸易商销售、门店采购
* 列：单据、单号、买方、卖方、金额、状态。金额为该单据商品售价合计：冷丰销售和供应链采购为原始售价，门店采购为售价 × 门店结算系数，贸易商销售为售价 × 贸易商结算系数。单号可点击打开对应详情
* 尚未生成时展示空态「暂无关联购销单」

操作记录按时间倒序展示，列：变更内容、变更人、变更时间。没有记录时显示「暂无操作记录」。

* 已有需求单补一条「发布需求单」，变更人为创建人，时间为创建时间
* 门店新发布同样记「发布需求单」
* 状态变化记具体动作和「状态：原状态 → 新状态」，例如初审通过、接单、撤回接单、确认签约、合同签署完成、复核通过、作废、审核驳回、需求完成
* 未全部签完时，每签一份记「签署」加合同名称
* 待接单到支付中修改结算比例记「修改结算比例」
* 复核通过生成购销单记「生成冷丰销售单、贸易商销售单、供应链采购单、门店采购单」
* 变更人用这次操作的人：发布是门店、接单/签约是贸易商、审核和改比例是王丽、作废是平台或操作人

#### 1.2.6 额度联动（本页视角）

| 动作 | 已占用（仅需求门店） | 已成交（仅需求门店） | 可用额度 |
| --- | --- | --- | --- |
| 门店端发布成功 | +总金额 | 不变 | 随已占用减少 |
| 审核驳回 / 门店取消 / 平台作废 / 需求完成 | −总金额（若曾占用） | 完成不因释放而减少已成交 | 随已占用回升 |
| 复核通过进入支付中（后续流程） | 不变 | +总金额 | 不变（已成交不扣可用） |

门店管理列表「已占用」可点击，弹窗列出占用该店额度的进行中需求（本店为需求门店，且未释放占用）。详见《门店管理PRD》。

#### 1.2.7 数据范围

* 需求数据与门店端、审核中心同源
* 门店额度与门店管理同源
* 商品包、产品配置分别来自对应 B 端配置

## 2. 界面说明

* 列表风格与 RBT 其他管理页一致（Schema Table）
* 详情为右侧宽抽屉，页签为基础信息、操作记录；基础信息为区块标题 + 信息网格 / 表格
* 合同预览为居中弹层，叠在详情之上
* 「签署」为居中弹层，留在需求单管理页查看签署进度

## 3. 非目标

* 本页不提供新建 / 编辑需求、不直接审核通过或驳回
* 本页不直接完成接单或支付。「待签署」弹出三份协议查看进度；本页只由冷丰供应链确认采购合同，不代门店或贸易商签署
* 审核中心菜单与审核操作细节见《需求单审核PRD》；门店端发布见《门店端移动端PRD》
