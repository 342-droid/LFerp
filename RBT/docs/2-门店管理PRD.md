## 1. 需求描述

### 1.1 RBT 下新增门店准入管理

顶部导航最后两项为「RBT」「RBT-移动端」。进入 RBT 后，左侧菜单为「首页」「门店准入管理」「商品包」「产品配置」「需求单管理」「交易单」「履约」。贸易商、服务商在业务伙伴的档案里维护，不在本页。

原型页面：`RBT/rbt_admit_store.html`

本页维护已准入门店。门店资料从门店档案带出。RBT 等级、状态、额度、需求次数、保证金和 RBT 标签在本页维护。需求由平台在需求单管理代门店发布，发布时占用本页额度。

### 1.2 逻辑说明

#### 1.2.1 查询

查询条件按以下顺序展示。门店编码、门店名称、联系人姓名、联系人手机号、法人姓名、法人手机号为包含匹配，不区分大小写。RBT等级、RBT标签为精确匹配。条件可只填一部分。

- 门店编码
- 门店名称
- RBT等级：下拉框，枚举 A、B、C、D
- 联系人姓名：匹配列表「联系人」
- 联系人手机号
- 法人姓名
- 法人手机号
- RBT标签：下拉框，选项为门店标签库中启用的标签。门店只要带有所选标签即命中
- 「查询」按当前条件刷新，并回到第 1 页
- 「重置」清空条件，恢复全部记录
- 重新查询、重置、切换分页后，已勾选的门店清空

#### 1.2.2 列表

表格最左为勾选列。门店编码固定在左侧，操作列固定在右侧。

- 门店编码：可点击，在当前页打开详情，地址不变
- 门店名称
- RBT等级：A、B、C、D
- 状态：启用、禁用
- RBT标签：可多个；无标签展示「—」
- 门店总额度：金额，保留两位小数，单位元
- 已占用：金额，保留两位小数，单位元；大于 0 时可点击，弹窗列出当前占用该门店额度的需求单
- 已成交：金额，保留两位小数，单位元。只累计已进入门店付款中或已完成的需求商品金额，不按总金额，也不按实发
- 可用额度：门店总额度 − 已占用，保留两位小数，单位元；小于 0 时按 0 展示。已成交不扣减可用额度
- 需求次数：正整数，默认 1。未结束需求达到该次数后不能再发布。未结束含待接单、待确认签约、待重新确认、待签署、发货中、门店付款中、已完成。不含已作废、已驳回
- 保证金：已缴纳、未缴纳。还没选择时为「—」
- 门店合作类型
- 门店类型
- 事业线
- 品牌名称
- 业务线：多个时用顿号拼接
- 联系人
- 联系人手机号：可复制
- 法人姓名
- 法人手机号：可复制
- 配送仓库
- 省市区：展示时在斜杠两侧加空格
- 详细地址
- 创建人
- 创建时间
- 更新人
- 更新时间
- 操作：固定在右侧，按钮为「编辑」「启用」或「禁用」

分页默认每页 20 条，可选 20、50、100、200。无数据时展示空列表。

已占用大于 0 时，点击金额打开「已占用需求单 · 门店名称」。只列本店作为需求门店、且尚未释放占用的需求。已作废、已驳回、已完成不出现。列：需求单号、商品包、商品金额、服务费、总金额、状态、需求门店、创建时间。没有数据时为「暂无占用中的需求单」。点「关闭」收起。

列表上方按钮：

- 新增准入门店
- 标签管理

#### 1.2.3 新增准入门店

点击「新增准入门店」，打开「新增准入门店」。

- 门店：下拉框，数据从门店档案选取，展示「门店名称（门店编码）」，必选
- RBT等级：下拉框，枚举 A、B、C、D，手动选择，必选
- 状态：下拉框，枚举启用、禁用，必选，默认启用
- 门店额度：数字输入，单位元，必填，须大于 0，最多两位小数。保存后作为门店总额度，已占用与已成交初始为 0
- 需求次数：数字输入，单位次，必填，须为大于 0 的整数，默认为 1，可修改。未结束需求达到该次数后不能再发布
- 保证金是否缴纳：是 / 否，必选。选「否」可以不上传凭证。选「是」必须上传缴纳凭证，支持图片或 PDF，不超过 10M
- 缴纳凭证：选「是」时显示上传，旁注「支持图片或 PDF，不超过 10M」。未选或选「否」时提示「选择「是」后上传凭证」，保存不保留凭证
- RBT标签：下拉多选，数据来自门店标签库中启用的标签，可不选
- 其余字段根据所选门店自动填充，不允许修改
  - 门店编码：取档案门店编码
  - 门店名称
  - 门店合作类型
  - 门店类型
  - 事业线
  - 品牌名称
  - 业务线：多个时用顿号拼接
  - 联系人姓名
  - 联系人手机号：取档案展示值
  - 法人姓名：档案没有该字段时为「—」
  - 法人手机号：档案没有该字段时为「—」
  - 配送仓库
  - 省市区
  - 详细地址
- 未选门店时，锁定字段为空，提示「选择门店后自动带出」
- 清空已选门店后，锁定字段一并清空
- 更换门店只刷新锁定字段，不清空已填的 RBT 等级、门店额度、需求次数、保证金是否缴纳和 RBT标签

保存：

- 未选门店：提示「请选择门店」，不保存
- 未选 RBT 等级：提示「请选择RBT等级」，不保存
- 未选状态：提示「请选择状态」，不保存
- 未填门店额度：提示「请输入门店额度」，不保存
- 门店额度格式非法：提示「门店额度仅支持数字，最多两位小数」，不保存
- 门店额度不大于 0：提示「门店额度须大于 0」，不保存
- 未填需求次数：提示「请输入需求次数」，不保存
- 需求次数不是大于 0 的整数：提示「需求次数须为大于 0 的整数」，不保存
- 未选保证金是否缴纳：提示「请选择保证金是否缴纳」，不保存
- 选「是」但没上传凭证：提示「请上传保证金缴纳凭证」，不保存
- 凭证超过 10M：提示「凭证文件请控制在 10M 以内」，不保存
- RBT标签允许为空
- 保存后的门店编码就是档案门店编码，不再另编编码
- 该档案门店已在准入列表中：提示「该门店已在准入列表中」，弹窗不关闭，不新增第二条。按档案门店编码或已有准入记录上记下的档案编码判断
- 已选标签时，绑定到新门店；未选则该门店无标签
- 保存成功提示「准入门店已新增」，关闭弹窗并回到第 1 页
- 操作记录记「新增准入门店」。选了标签再记一条「RBT标签：无 → 标签名」

#### 1.2.4 编辑准入门店

操作列「编辑」打开「编辑准入门店」。字段、顺序、只读样式与新增一致。仅允许修改 RBT 等级、状态、门店额度、需求次数、保证金是否缴纳、缴纳凭证和 RBT标签。

- 门店：带出当前门店，不允许修改
- RBT等级：带出当前等级，可修改，必选
- 状态：带出当前状态，可修改，必选。启用、禁用
- 门店额度：带出当前门店总额度，可修改，必填。不改动已占用、已成交
- 需求次数：带出当前次数，可修改，必填，须为大于 0 的整数
- 保证金是否缴纳：带出当前选择，可改为是或否。还没选过的要重新选择
- 缴纳凭证：当前已缴纳且有凭证时带出文件名，可以重新上传。改为「否」后清空凭证
- RBT标签：带出当前标签，可增删，可以清空
- 其余字段带出这条准入记录上的现有资料，不允许修改。保存时不回写这些字段

保存：

- 未选 RBT 等级：提示「请选择RBT等级」，不保存
- 门店额度、需求次数、保证金校验与新增一致
- 只更新 RBT 等级、状态、门店额度、需求次数、保证金是否缴纳、缴纳凭证、RBT标签、更新人、更新时间
- 更新人记为「用户名」，更新时间记为保存时间
- 门店编码不变
- 清空标签后，列表该 RBT标签为「—」
- 没有字段变化时不另记一条空的编辑记录。标签有变化时仍记标签变更
- 保存成功提示「门店已更新」，停留在当前页码

#### 1.2.5 勾选与批量标签

每行可勾选，表头可全选当前页。勾选后，列表上方出现「已选择 N 项」，并提供「添加标签」「移出标签」。关闭该栏即清空勾选。未勾选时不出现这两个按钮。没勾选就点批量时提示「请先勾选门店」。

两个操作都要先选择至少一个标签，标签来自门店标签库中启用的标签，可多选。未选标签时提示「请选择RBT标签」，不保存。

- 添加标签：把所选标签加到已勾选门店上
  - 门店原来的其他标签保留
  - 已经有的标签不重复添加
  - 成功提示「已添加标签」
- 移出标签：只从已勾选门店去掉所选标签
  - 未选中的标签保留
  - 某家门店本来没有该标签时，这家可跳过，不影响其他门店
  - 成功提示「已移出标签」

批量结果立即反映到列表标签列。标签有变化时，操作记录记「RBT标签：原标签 → 新标签」。原来没有写「无」，多个标签用顿号。

#### 1.2.6 标签管理

「标签管理」打开「门店标签库」，用于维护标签本身，不直接改某一家门店的绑定。

- 新增、编辑、批量操作、查询里的 RBT标签，都使用标签库中启用的标签
- 标签库和列表上的 RBT标签不预置示例数据。打开页面时去掉已写入本地的示例标签「担保门店」「需求门店」及其打标。手动新增的标签保留
- 标签库可继续新增标签，名称不限死
- 停用或未启用的标签不出现在可选项中

#### 1.2.8 重复准入

- 同一家档案门店只允许准入一次
- 原型中已有 ONS00001 至 ONS00005 五条示例，已分别对应五家档案门店，这五家按已准入处理，不能再新增
- 新准入记录的门店编码使用档案门店编码

#### 1.2.9 启用与禁用

新准入的门店默认启用。操作列按当前状态显示按钮：启用中显示「禁用」，已禁用显示「启用」。

- 点击「禁用」后该门店变为禁用，提示「已禁用」，更新人、更新时间记为本次操作
- 点击「启用」后恢复启用，提示「已启用」，更新人、更新时间记为本次操作
- 禁用的门店仍留在门店准入管理中，仍可查看和编辑
- 禁用门店不出现在丰银宝门店端的可选门店里。同一手机号下若还有其他启用门店，仍可进入那些启用门店
- 已经进入某店后，若该店被禁用，再次打开门店端时不再进入这家店。还有其他启用门店时进入其中一家；没有时停在选择门店

#### 1.2.10 额度与需求单联动

可用额度始终是：门店总额度 − 已占用。已成交不扣可用额度。

| 动作 | 已占用 | 已成交 | 可用额度 |
| --- | --- | --- | --- |
| 平台代门店发布成功 | +商品金额 | 不变 | 随已占用减少 |
| 进入已作废、已驳回、已完成 | 释放当时占用的商品金额 | 完成不因释放而减少 | 随已占用回升 |
| 确认发货完成，进入门店付款中 | 不变 | +商品金额 | 不变 |

发布前还须同时满足，否则不生成需求：

- 保证金已缴纳。未缴纳或还没选择时提示「保证金未缴纳，无法发布需求」
- 可用额度大于 0，且商品金额小于等于可用额度
- 未结束需求条数小于需求次数。达到次数时提示「需求次数已达上限，无法发布需求」

待接单、待确认签约、待重新确认、待签署、发货中、门店付款中都占用额度。发货中不释放。已成交要等确认发货完成、进入门店付款中才增加。
