## 1. 需求描述

### 1.1 RBT 下新增门店管理

顶部导航最后两项为「RBT」「RBT-移动端」。进入 RBT 后，左侧菜单为「首页」「门店管理」「商品包」「产品配置」「需求单管理」。贸易商在业务伙伴的贸易商档案维护。

原型页面：`RBT/rbt_admit_store.html`

### 1.2 逻辑说明

#### 1.2.1 查询

查询条件按以下顺序展示。门店编码、门店名称、联系人姓名、联系人手机号、法人姓名、法人手机号为包含匹配，不区分大小写。RBT等级、门店标签为精确匹配。条件可只填一部分。

- 门店编码
- 门店名称
- RBT等级：下拉框，枚举 A、B、C、D
- 联系人姓名：匹配列表「联系人」
- 联系人手机号
- 法人姓名
- 法人手机号
- 门店标签：下拉框，选项为门店标签库中启用的标签。门店只要带有所选标签即命中
- 「查询」按当前条件刷新，并回到第 1 页
- 「重置」清空条件，恢复全部记录
- 重新查询、重置、切换分页后，已勾选的门店清空

#### 1.2.2 列表

表格最左为勾选列，其次为序号。门店编码固定在左侧，操作列固定在右侧。

- 门店编码：可点击，在当前页打开详情，地址不变
- 门店名称
- RBT等级：A、B、C、D
- 状态：启用、禁用
- 门店标签：可多个；无标签展示「—」
- 门店总额度：金额，保留两位小数，单位元
- 已占用：金额，保留两位小数，单位元；大于 0 时可点击，弹窗列出当前占用该门店额度的需求单（本店为需求门店，且需求未释放占用：非已作废/已驳回/已完成），展示需求单号、商品包、商品金额、联营服务费、总金额、状态、需求门店、创建时间
- 已成交：金额，保留两位小数，单位元；仅累计需求单「复核通过」写入的成交金额，不另做演示假数据
- 可用额度：门店总额度 − 已占用，保留两位小数，单位元；小于 0 时按 0 展示（已成交不扣减可用额度）
- 门店合作类型
- 门店类型
- 事业线
- 品牌名称
- 业务线：多个时用顿号拼接
- 联系人
- 联系人手机号：可复制
- 法人姓名
- 法人手机号：可复制
- 配送仓库
- 省市区：展示时在斜杠两侧加空格
- 详细地址
- 创建人
- 创建时间
- 更新人
- 更新时间
- 操作：固定在右侧，按钮为「编辑」「启用」或「禁用」

分页默认每页 20 条，可选 20、50、100、200。无数据时展示空列表。

列表上方按钮：

- 新增准入门店
- 标签管理

#### 1.2.3 新增准入门店

点击「新增准入门店」，打开「新增准入门店」。

- 门店：下拉框，数据从门店档案选取，展示「门店名称（门店编码）」，必选
- RBT等级：下拉框，枚举 A、B、C、D，手动选择，必选
- 状态：下拉框，枚举启用、禁用，必选，默认启用
- 门店额度：数字输入，单位元，必填，须大于 0，最多两位小数；保存后作为门店总额度，已占用与已成交初始为 0
- 门店标签：下拉多选，数据来自门店标签库，可不选
- 其余字段根据所选门店自动填充，不允许修改
  - 门店编码：取档案门店编码
  - 门店名称
  - 门店合作类型
  - 门店类型
  - 事业线
  - 品牌名称
  - 业务线：多个时用顿号拼接
  - 联系人姓名
  - 联系人手机号：取档案展示值
  - 法人姓名：档案没有该字段时为「—」
  - 法人手机号：档案没有该字段时为「—」
  - 配送仓库
  - 省市区
  - 详细地址
- 未选门店时，锁定字段为空，提示「选择门店后自动带出」
- 清空已选门店后，锁定字段一并清空
- 更换门店只刷新锁定字段，不清空已填的 RBT 等级、门店额度和门店标签

保存：

- 未选门店：提示「请选择门店」，不保存
- 未选 RBT 等级：提示「请选择RBT等级」，不保存
- 未选状态：提示「请选择状态」，不保存
- 未填门店额度：提示「请输入门店额度」，不保存
- 门店额度格式非法：提示「门店额度仅支持数字，最多两位小数」，不保存
- 门店额度不大于 0：提示「门店额度须大于 0」，不保存
- 门店标签允许为空
- 保存后的门店编码就是档案门店编码，不再另编编码
- 该档案门店已在准入列表中：提示「该门店已在准入列表中」，弹窗不关闭，不新增第二条
- 已选标签时，绑定到新门店；未选则该门店无标签
- 保存成功提示「准入门店已新增」，关闭弹窗并回到第 1 页

#### 1.2.4 编辑准入门店

操作列「编辑」打开「编辑准入门店」。字段、顺序、只读样式与新增一致。仅允许修改 RBT 等级、状态、门店额度和门店标签。

- 门店：带出当前门店，不允许修改
- RBT等级：带出当前等级，可修改，必选
- 状态：带出当前状态，可修改，必选。启用、禁用
- 门店额度：带出当前门店总额度，可修改，必选；不改动已占用、已成交
- 门店标签：带出当前标签，可增删，可以清空
- 其余字段带出这条准入记录上的现有资料，不允许修改；保存时不回写这些字段

保存：

- 未选 RBT 等级：提示「请选择RBT等级」，不保存
- 门店额度校验与新增一致
- 只更新 RBT 等级、状态、门店额度、门店标签、更新人、更新时间
- 更新人记为当前操作人，更新时间记为保存时间
- 门店编码不变
- 清空标签后，列表该门店标签为「—」
- 保存成功提示「门店已更新」，停留在当前页码

#### 1.2.5 勾选与批量标签

每行可勾选，表头可全选当前页。勾选后，列表上方出现「已选择 N 项」，并提供「添加标签」「移出标签」。关闭该栏即清空勾选。未勾选时不出现这两个按钮。

两个操作都要先选择至少一个标签，标签来自门店标签库，可多选。未选标签时提示「请选择门店标签」，不保存。

- 添加标签：把所选标签加到已勾选门店上
  - 门店原来的其他标签保留
  - 已经有的标签不重复添加
  - 成功提示「已添加标签」
- 移出标签：只从已勾选门店去掉所选标签
  - 未选中的标签保留
  - 某家门店本来没有该标签时，这家可跳过，不影响其他门店
  - 成功提示「已移出标签」

批量结果立即反映到列表标签列。

#### 1.2.6 标签管理

「标签管理」打开门店标签库，用于维护标签本身，不直接改某一家门店的绑定。

- 新增、编辑、批量操作里的门店标签，都使用标签库中启用的标签
- 标签库和列表上的门店标签不预置示例数据。打开页面时去掉已写入本地的示例标签「担保门店」「需求门店」及其打标；手动新增的标签保留
- 标签库可继续新增标签，名称不限死
- 停用或未启用的标签不出现在可选项中

#### 1.2.7 门店详情

点击门店编码，在当前页右侧打开「门店详情」。地址不变。

- 关闭：关闭按钮、点击遮罩、按 Esc
- 页头：门店名称、门店状态、运营状态、RBT 等级、门店编码、所属组织、门店标签
- 页签三个：基础信息、进件信息、操作记录

基础信息页签：

- 门店编码
- 主体名称
- 联系人
- 联系人手机号
- 门店名称
- 门店简称
- 门店合作类型
- 门店类型
- 事业线
- 品牌名称
- 业务线：多个时用顿号拼接
- RBT等级
- 状态：启用、禁用
- 门店标签
- 绑定BD
- 配送仓库
- 省市区
- 详细地址
- 经纬度
- 运营状态
- 营业时间
- 进件状态
- 余额支付
- 结算类型
- 结算周期
- 分账服务
- 门店状态
- 可提现手机号
- 门头/场地照
- 内景/工作区域照
- 收银台/前台照
- 门店仓库

基础信息页签内另有「额度信息」：

- 门店总额度
- 已占用
- 已成交
- 可用额度：门店总额度 − 已占用

进件信息展示该门店已有进件资料。不包含商户进件，不提供「去进件」。

详情里的标签与列表使用同一套绑定。列表里改标签后，若详情仍打开，标签同步更新。

操作记录按时间倒序展示，列：变更内容、变更人、变更时间。没有记录时显示「暂无操作记录」。

- 已有门店补一条「新增准入门店」，变更人为创建人，时间为创建时间
- 新准入同样记「新增准入门店」；若准入时选了标签，再记一条标签变更
- 编辑只记录实际变化的字段，格式为「字段名：原值 → 新值」；一次改多项用分号连接。没有变化不记
- 启用、禁用记「状态：启用 → 禁用」或相反
- 添加、移出、编辑里改标签，记「门店标签：原标签 → 新标签」；原来没有写「无」，多个标签用顿号
- 已占用、已成交金额变化各记一条，金额带到「元」
- 门店管理里的操作，变更人记「用户名」。额度随需求单占用、释放或复核增加已成交时，变更人取该需求的更新人，没有则取创建人

#### 1.2.8 重复准入

- 同一家档案门店只允许准入一次
- 原型中已有 ONS00001 至 ONS00005 五条示例，已分别对应五家档案门店，这五家按已准入处理，不能再新增
- 新准入记录的门店编码使用档案门店编码

#### 1.2.9 启用与禁用

新准入的门店默认启用。操作列按当前状态显示按钮：启用中显示「禁用」，已禁用显示「启用」。

- 点击「禁用」后该门店变为禁用，提示「已禁用」，更新人、更新时间记为本次操作
- 点击「启用」后恢复启用，提示「已启用」，更新人、更新时间记为本次操作
- 禁用的门店仍留在门店管理中，仍可查看和编辑
- 门店端不可使用禁用门店的联系人手机号、法人手机号登录。登录时提示「该门店已禁用，无法登录」。已登录的会话在再次进入门店端时退出
- 同一手机号下若还有其他启用门店，仍可登录那些启用门店

#### 1.2.10 额度与需求单联动

- 发布需求成功：只给需求门店增加「已占用」（金额为总金额）；发布前只校验需求门店可用额度 ≥ 总金额
- 需求进入「已作废」「已驳回」「已完成」：只释放该需求占用的需求门店「已占用」
- 需求「复核通过」（待复核 → 支付中）：仅需求门店增加「已成交」（金额为总金额）；已成交不扣减可用额度
- 可用额度始终按：门店总额度 − 已占用
