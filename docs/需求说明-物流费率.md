## 1. 全局说明

1. 始发地有效校验

   1. 查询始发地下拉：取仓库档案全部记录，不限制是否启用/禁用，展示「仓库编码+仓库名称」拼接；

   2. 新增始发地下拉：仅取仓库档案是否启用=启用的记录；

   3. 编辑始发地下拉：取是否启用=启用的记录，并保留当前记录已选始发地（即使该仓库后来被禁用），允许原样保存；

   4. 保存时始发地未选，拦截并弹出提示「请选择始发地」；

2. 承运商有效校验

   1. 查询承运商下拉：取承运商全部记录，不限制是否启用/禁用，展示「承运商编码+承运商名称」拼接；

   2. 新增承运商下拉：仅取承运商是否启用=启用的记录；

   3. 编辑承运商下拉：取是否启用=启用的记录，并保留当前记录已选承运商（即使该承运商后来被禁用），允许原样保存；

   4. 保存时承运商未选，拦截并弹出提示「请选择承运商」；

3. 费率唯一校验

   1. 重量计费唯一键=始发地+承运商+订单渠道+物流类型+目的省+目的市+目的区；金额计费唯一键=始发地+承运商+订单渠道+目的省+目的市+目的区（不含物流类型）。唯一键均不含费用方案。

   2. 新增、编辑保存时，按本条费用方案对应的唯一键查询物流费率表；编辑时排除当前记录本身；

   3. 目的市、目的区为空时，空值参与比较（只到省的记录，与填了市/区的记录不视为同一条）；

   4. 命中已有记录，拦截并弹出提示「已存在相同的物流费率，请勿重复保存」；

   5. 启用互斥：保存为启用时，按始发地+订单渠道+目的省+目的市+目的区查询其他启用记录（编辑排除自身；不限承运商、不限物流类型）。本条是金额计费且已有启用重量计费，或本条是重量计费且已有启用金额计费，拦截并弹出提示「同一配送仓、订单渠道、目的地不可同时启用重量计费与金额计费」。禁用记录不参与该互斥。

4. 目的区域填写规则

   1. 目的省必填；可填行政区名称，或填「全国」表示全国兜底（此时目的市、目的区必须为空）；

   2. 填写目的区时，目的市必须已填，否则拦截并弹出提示「请先选择目的市」；目的省=全国时不得填市、区；

   3. 只填省：目的市、目的区为空，表示该省；

   4. 填省+市、目的区为空，表示该市；

   5. 填省+市+区，表示该区；

   6. 目的省=全国：全国兜底费率；

5. 物流费用阶梯校验

   1. 费用方案=重量计费：首重重量、首重价必填且>0；至少一档续重；第一档起始重量=首重重量；相邻档连续（下一档起始=上一档结束）、不重叠、无空洞；续价允许0；结束重量>起始重量；最后一档结束重量必须为无穷大；

   2. 费用方案=金额计费：不填首重；至少一档；第一档起始金额=0；相邻档连续、不重叠、无空洞；运费允许0；结束金额>起始金额；最后一档结束金额必须为无穷大；

   3. 最后一档结束由系统写入无穷大，页面展示「∞」且不可编辑；不允许将最后一档结束写成有限值（含9999）；导入时最后一档结束须填「∞」或「INF」，见序号2；

   4. 校验不通过时：首重重量未填或≤0，拦截并弹出提示「请填写首重重量」；首重价未填或≤0，拦截并弹出提示「请填写首重价」；其余阶梯问题（缺档、不连续、重叠、有空洞、最后一档非无穷大、重量计费缺续价、金额计费缺运费），拦截并弹出提示「请填写物流费用」；

6. 折扣空值规则

   1. 运费折扣、结算折扣允许不填；不填时保存为1.00；

   2. 填写时须在0.10~1.00（含）之间；运费折扣超范围，拦截并弹出提示「运费折扣须在0.10~1.00之间」；结算折扣超范围，拦截并弹出提示「结算折扣须在0.10~1.00之间」；

7. 启用状态删除校验

   1. 是否启用=启用，不允许删除，弹出提示「当前物流费率为启用状态，不允许删除」；须先改为禁用后再删除；

8. 增值服务项目唯一

   1. 同一条费率下，增值服务项目不可重复；重复则拦截并弹出提示「增值服务项目不可重复」；

10. 重抛比与计费重量

    1. 重抛比 A:B 表示 A 吨货物对应 B 立方米，即 A×1000 kg : B CBM。例：1:3 表示 1000kg : 3CBM；

    2. 体积重量(kg) = 长(cm) × 宽(cm) × 高(cm) ÷ (1000 × B / A)。1:3 时除数为 3000；

    3. 计费重量 = max(订单重量, 体积重量)，保留 3 位小数；费率未配置重抛比，或该类型长、宽、高任一为0或不传时，计费重量=订单重量，不做抛重；

    4. 常温、冷链使用各自的重量与长宽高，分别计算计费重量；

11. 下单费率匹配

    1. 只匹配是否启用=启用的记录；费率启用即可，不因仓库/承运商后来禁用而排除；

    2. 目的地按粒度从细到粗：区 → 市 → 省 → 全国（目的省=全国且市、区为空）。按配送仓+订单渠道查找启用费率，不按费用方案优先；某一档存在启用费率即确定整单费用方案（该档因启用互斥只会是金额计费或重量计费），不再改用更粗档的另一种方案；

    3. 承运商不作为匹配入参，由匹配结果返回。重量计费时常温、冷链可返回不同承运商；金额计费只返回一个承运商。

    4. 金额计费：用确定方案的那一档，整单只算一次。重量计费：常温、冷链分开匹配，各自按区 → 市 → 省 → 全国查找启用的重量计费（可不同目的地粒度、不同承运商）；只找重量计费，不改走更粗档的金额计费。某侧从区到全国都没有，则该侧匹配失败。

    5. 匹配不到对应启用费率，拦截下单，并按全局说明-12触发预警。

12. 下单预警

    1. 以下情形触发系统预警（可同时多条原因）；预警不替代拦截，该拦截的仍拦截；

    2. 预警原因：

        | 原因 | 触发条件 |
        | --- | --- |
        | 重量为0 | 重量计费：该物流类型参与计算且订单重量=0（含常温、冷链均为0而取第一档）。金额计费：常温重量与冷链重量均为0 |
        | 体积为0 | 仅重量计费：该物流类型参与计算，且长、宽、高任一为0或不传。金额计费不报体积为0 |
        | 未匹配到费率 | 区到全国都没有启用费率；或整单已定为重量计费，需计算的一侧从区到全国都没有启用重量计费 |
        | 命中全国兜底 | 匹配结果为目的省=全国的费率 |

    3. 预警内容至少包含：配送仓、门店编码、门店名称、订单号、订单渠道、履约方式、物流类型、目的省市区、原因。金额计费时物流类型带「不区分」；重量计费按常温或冷链带出。

    4. 通道：企微群；接收人：谢威、袁杰、符洪斌、吴丹萍；

## 6. 费率匹配与计算规则

### 6.1 系统用例

### 6.3 计算公式（配置展示口径）

重量计费页面说明：运费 = 首重价 + 续价 × (实重 − 首重重量)；续价取实重所在区间。运行时「实重」取计费重量（含抛重）。

上楼费页面说明：结算重量不超过免上楼重量时免费；有电梯/无电梯：基础费 + 重量系数×重量 + 楼层系数×楼层数；1楼不上楼，上楼费为 0。件数系数可配置，计算暂不参与。
