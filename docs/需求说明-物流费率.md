## 1. 范围与概念

### 1.1 菜单与原型

冷丰 TMS：路由规则、承运商、物流费率表、运费预估报表。

| 页面 | 原型 |
| --- | --- |
| 物流费率表（含导入弹窗） | `SCM/logistics_rate.html` |
| 运费预估报表 | `SCM/freight_estimate_report.html` |

### 1.2 用例一览

| 编号 | 名称 | 做什么 |
| --- | --- | --- |
| UC01 | 物流费率维护 | 查询、新增、编辑、详情、删除；通过编辑切换启用/禁用 |
| UC02 | 导入物流费率 | 按模板导入 xlsx，整文件校验通过后**仅新增** |

| 枚举 | 取值 |

### 1.4 概念（后文不再解释）

| 概念 | 一句话 |
| --- | --- |
| 唯一键 | 管「能不能存成两条」（含禁用），见 [§3.1](#31-唯一键) |
| 线路 | 始发地 + 订单渠道 + 目的省 + 目的市 + 目的区；市、区空值参与比较 |
| 启用互斥 | 同一线路启用态：金额最多 1 条，或重量常温最多 1 条 + 冷链最多 1 条；金额与重量不可同时启用，见 [§3.2](#32-启用互斥) |
| 下单匹配 | 不管承运商，按配送仓+订单渠道+目的地从细到粗，见 [§9.2](#92-匹配规则) |
| 始发地 / 配送仓 | 配置页叫始发地，下单和报表叫配送仓，是同一个仓 |
| 全国兜底 | 目的省填「全国」且市、区为空 |

### 1.5 本期已写明不做

以下是正文已有结论，不是待定：

- 出库称重后**不重算**运费（下单价即最终价）
- 履约方式（配送、快递）**不参与匹配**，仅随预警、报表带出
- 上楼费**件数系数**可配置、导入必填，计算暂不使用
- 物流费率表**不提供试算**
- 导入**只新增、不更新**已有费率

## 2. 主数据与填写规则

### 2.1 始发地

展示：仓库编码+仓库名称。

| 场景 | 下拉范围 |
| --- | --- |
| 查询 | 仓库档案全部，不限制启用/禁用 |
| 新增 | 仅是否启用=启用 |
| 编辑 | 启用记录 + 当前已选值（即使后来被禁用），允许原样保存 |

保存时未选：提示「请选择始发地」。未命中仓库档案：提示「始发地无效，请重新选择」。

### 2.2 承运商

展示：承运商编码+承运商名称。查询 / 新增 / 编辑范围同 [§2.1](#21-始发地)（换成承运商档案）。

保存时未选：提示「请选择承运商」。未命中承运商档案：提示「承运商无效，请重新选择」。

### 2.3 目的区域

目的省必填；可填行政区名称，或填「全国」表示全国兜底（此时目的市、目的区必须为空）。

| 填法 | 含义 |
| --- | --- |
| 只填省，市、区空 | 该省 |
| 省+市，区空 | 该市 |
| 省+市+区 | 该区 |
| 目的省=全国，市、区空 | 全国兜底费率 |

填写目的区时，目的市必须已填，否则提示「请先选择目的市」。目的省=全国时不得填市、区，否则提示「全国兜底不得填写市、区」。目的省为空：提示「请选择目的区域」。

### 2.4 折扣

运费折扣、结算折扣允许不填；不填时保存为 1.00。填写时须在 0.10～1.00（含）之间。

| 超范围 | 提示 |
| --- | --- |
| 运费折扣 | 运费折扣须在0.10~1.00之间 |
| 结算折扣 | 结算折扣须在0.10~1.00之间 |

单位：折。

### 2.5 删除

是否启用=启用，不允许删除，提示「当前物流费率为启用状态，不允许删除」；须先改为禁用后再删除。禁用记录二次确认后删除。

### 2.6 其它表单规则

- 物流时效：非必填，单位天；已填且小于 0，提示「物流时效不能小于0」
- 是否启用：新增默认启用
- 增值服务、上楼费：新增默认否；=是时展开对应明细
- 增值服务=否，不保存增值服务明细；上楼费=否，不保存上楼费明细
- 列表分页展示

## 3. 唯一与互斥

### 3.1 唯一键

不含费用方案。目的市、目的区为空时，空值参与比较（只到省的记录，与填了市/区的记录不视为同一条）。重量、金额用同一套键；金额计费物流类型固定为「不区分」。

**始发地 + 承运商 + 订单渠道 + 物流类型 + 目的省 + 目的市 + 目的区**

因此：同一线路、同一温层（常温 / 冷链 / 不区分）可以存多家承运商费率，包括多条禁用；完全相同（含同一承运商）不能再存一条。

新增、编辑保存时按上列唯一键查询；编辑时排除当前记录本身。命中已有记录，提示「已存在相同的物流费率，请勿重复保存」。新增成功后唯一键都可改，保存时再做唯一校验。

### 3.2 启用互斥

只约束**启用**记录；禁用不占名额。保存为启用时，按 [§1.4](#14-概念后文不再解释) 线路查询其他启用记录（编辑排除自身；不限承运商）：

| 本条 | 同线路已有启用 | 提示 |
| --- | --- | --- |
| 金额计费 | 任一重量计费 | 同一配送仓、订单渠道、目的地不可同时启用重量计费与金额计费 |
| 重量计费 | 任一金额计费 | 同一配送仓、订单渠道、目的地不可同时启用重量计费与金额计费 |
| 金额计费 | 另一条金额计费 | 同一配送仓、订单渠道、目的地只能启用一条金额计费 |
| 重量-常温 | 另一条常温 | 同一配送仓、订单渠道、目的地只能启用一条常温重量计费 |
| 重量-冷链 | 另一条冷链 | 同一配送仓、订单渠道、目的地只能启用一条冷链重量计费 |

允许：

- 同一线路启用常温 + 冷链（重量方案）；两家承运商可相同（都顺丰）或不同（常温中通、冷链韵达）
- 同一线路只启用常温或只启用冷链
- 同一温层多家承运商：仅一条启用，其余禁用

下单按物流类型分别匹配，同一温层启用最多一条，不会因多家承运商判重。

## 4. 阶梯与增值配置

### 4.1 物流费用阶梯

切换费用方案后按新方案重填物流费用，原方案数据不保留。

**重量计费**

- 首重重量、首重价写在每一档阶梯上，各档可不同；金额计费时这两列隐藏且不填
- 每档首重重量、首重价必填且 >0（单位 KG / 元）
- 至少一档；第一档起始重量=0 且不可改
- 相邻档连续（下一档起始=上一档结束）、不重叠、无空洞；续价允许 0；结束重量 > 起始重量
- 增加阶梯：在原最后一档之前插入有限结束档；原最后一档改为有限结束值，新档起始=该结束值，新档结束=无穷大；新档可带出上一档的首重重量、首重价，允许改成不同值
- 删除当前档，至少保留一档

**金额计费**

- 不填首重；至少一档；第一档起始金额=0 且不可改
- 相邻档连续、不重叠、无空洞；运费允许 0；结束金额 > 起始金额

**最后一档**

- 结束由系统写入无穷大，页面展示「∞」且不可编辑
- 不允许将最后一档结束写成有限值（含 9999）
- 导入时最后一档结束须填「∞」或「INF」（INF 大小写不敏感），见 [§7](#7-导入物流费率uc02)；导出统一写「∞」

**校验提示**

| 问题 | 提示 |
| --- | --- |
| 首重重量未填或 ≤0（任一带） | 请填写首重重量 |
| 首重价未填或 ≤0（任一带） | 请填写首重价 |
| 缺档、不连续、重叠、有空洞、最后一档非无穷大、重量计费缺续价、金额计费缺运费 | 请填写物流费用 |

页面配置展示（运行时「实重」取计费重量，见 [§9.3](#93-重抛比与计费重量)、[§9.4](#94-计算公式)）：

- 重量计费：命中档后，运费 = 该档首重价 + 该档续价 × (实重 − 该档首重重量)；实重不超过该档首重重量时只收该档首重价。各档首重、首重价可不同
- 上楼费：结算重量不超过免上楼重量时免费；有电梯/无电梯：基础费 + 重量系数×重量 + 楼层系数×楼层数；1 楼不上楼，上楼费为 0。件数系数可配置，计算暂不参与
- 保价费 = max(最低价, 订单应付金额 × 费率%)；按货品实际价值保价，不用订单实付

### 4.2 增值服务

增值服务=是时至少一行。同一条费率下项目不可重复，提示「增值服务项目不可重复」。未选项目或没有有效行，提示「请填写增值服务」。

| 项目 | 金额(每票) | 最低价(元) | 费率(%) |
| --- | --- | --- | --- |
| 保价费 | 禁用且清空 | 可填 | 可填 |
| 派送费 | 必填 | 置灰、不允许填写、须空 | 置灰、不允许填写、须空 |

### 4.3 上楼费用

上楼费=是时，免上楼重量及 8 个系数均必填（允许 0，不允许空），否则提示「请填写上楼费用」。免上楼重量单位 KG，≥0。

8 个系数：有电梯基础费 / 重量系数 / 楼层系数 / 件数系数；无电梯基础费 / 重量系数 / 楼层系数 / 件数系数。

件数系数仅保存，计算不使用，见 [§9.4](#94-计算公式)。

### 4.4 重抛比（配置）

双文本框，左:右，均可不填。列表未填展示「-」。计算口径见 [§9.3](#93-重抛比与计费重量)。

## 6. 物流费率维护（UC01）

查询、新增、编辑、详情、删除；通过编辑切换启用/禁用。无行上独立启用、禁用按钮。

前置：仓库档案、承运商已维护。

本页不覆盖：导入/导出见 [§7](#7-导入物流费率uc02)、[§8](#8-导出物流费率uc03)；下单公式见 [§9](#9-下单匹配计算与预警uc04)。

### 6.1 主路径

1. 菜单「物流费率表」进入列表
2. 选择查询条件（可不选），点「查询」
3. 已填条件全部 AND；未填不参与筛选；无条件返回全部，分页展示

### 6.2 失败 / 分支

| 条件 | 行为 |
| --- | --- |
| 点「重置」 | 清空查询条件并重新查询 |
| 目的区域只选省、不选市/区 | 查出目的省=该值的全部记录（含只到省、到市、到区） |
| 点列表「始发地」 | 打开「物流费率-详情」，全部只读，不可保存 |
| 点「新增」 | 打开「物流费率-新增」；是否启用默认启用，增值服务默认否，上楼费默认否 |
| 点「保存」 | 按 [§5](#5-保存校验清单) 顺序拦截，命中即提示、不落库 |
| 校验全部通过（新增） | 落库；创建人/更新人=当前账号，创建/更新时间=当前时间；关弹窗、刷新列表，提示「物流费率已保存」 |
| 点行「编辑」 | 打开「物流费率-编辑」，回填当前记录；不区分是否启用，唯一键均可修改；保存再走 [§5](#5-保存校验清单)（唯一校验排除自身）；成功后更新人/更新时间=当前 |
| 编辑「是否启用」并保存 | 完成启用/禁用切换；改为启用时仍走 [§3.2](#32-启用互斥) |
| 点行「删除」且当前为启用 | 不打开删除确认，提示「当前物流费率为启用状态，不允许删除」 |
| 点行「删除」且当前为禁用 | 二次确认后删除并刷新列表 |
| 点「导入」「导出」 | 见 [§7](#7-导入物流费率uc02)、[§8](#8-导出物流费率uc03) |

后置：列表为最新数据；新增/编辑成功已落库；删除成功已移除。

#### 文件与结构

**文件**

1. 未选择文件，则导入失败，失败原因：请先通过「文件浏览」选择 Excel 文件（不写导入记录）
2. 不是 .xlsx，则导入失败，失败原因：请上传 Excel 模板（.xlsx）（不写导入记录）

1. 三张表表头必须与模板完全一致（含括号说明），否则导入失败，失败原因：导入失败，请下载结果查看

**主表行数**

1. 主表数据行（不含表头、不含整行空行）超过 1000，则导入失败，失败原因：导入条数超过1000（写导入记录，结果文件不可下载）

#### 主表

**行号**

1. 必填，如为空，则导入失败，失败原因：行号为空
2. 校验当前文件主表中行号是否重复，如重复，则涉及行均导入失败，失败原因：文件内行号重复

**订单渠道（零售订单、代采订单）**

4. =否时，增值服务表不得出现该行号，否则导入失败，失败原因：增值服务为否时不应填写增值服务明细

2. 只能填「是」或「否」，否则导入失败，失败原因：请选择上楼费

#### 物流费用阶梯

**行号**

1. 必填，必须能挂到主表行号，否则导入失败，失败原因：存在无法关联的子表行号
2. 每个主表行号至少一档，否则导入失败，失败原因：请填写物流费用

**起始**

1. 必填，如为空，则导入失败，失败原因：请填写物流费用
2. 该行号下第一档起始必须为 0，否则导入失败，失败原因：请填写物流费用

**结束**

1. 必填，如为空，则导入失败，失败原因：请填写物流费用
2. 必须大于起始，否则导入失败，失败原因：请填写物流费用
3. 该行号下最后一档结束必须为「∞」或「INF」（INF 大小写不敏感）；写成有限值（含 9999），则导入失败，失败原因：请填写物流费用
4. 非最后一档结束必须为有限值，禁止用 9999 充当无穷大，否则导入失败，失败原因：请填写物流费用
5. 相邻档必须连续（下一档起始=上一档结束）、不重叠、无空洞，否则导入失败，失败原因：请填写物流费用

1. 费用方案=重量计费时，每一档必填且 >0，未填或 ≤0 则导入失败，失败原因：请填写首重重量

**首重价**

1. 费用方案=重量计费时，每一档必填且 >0，未填或 ≤0 则导入失败，失败原因：请填写首重价
2. 费用方案=金额计费时必须为空，如已填，则导入失败，失败原因：请填写物流费用

**续价或运费**

1. 必填，如为空，则导入失败，失败原因：请填写物流费用
2. 重量计费时本列为续价(元/KG)，允许 0
3. 金额计费时本列为该档运费，允许 0

**行号**

1. 必填，必须能挂到主表且主表增值服务=是，否则导入失败，失败原因：存在无法关联的子表行号
2. 主表增值服务=是但无本表对应行，则导入失败，失败原因：请填写增值服务
3. 主表增值服务=否但仍有本表该行号，则导入失败，失败原因：增值服务为否时不应填写增值服务明细

**项目（保价费、派送费）**

1. 必填，如为空，则导入失败，失败原因：请填写增值服务
2. 只能填「保价费」或「派送费」，否则导入失败，失败原因：请填写增值服务
3. 同一主表行号下项目不可重复，如重复，则导入失败，失败原因：增值服务项目不可重复

**金额(每票)**

1. 项目=保价费时必须为空
2. 项目=派送费时必填，未填则导入失败，失败原因：请填写增值服务

**最低价 / 费率(%)**

1. 项目=保价费时可填
2. 项目=派送费时必须为空，如已填，则导入失败，失败原因：请填写增值服务

#### 唯一与启用

**唯一键**

按 **始发地 + 承运商 + 订单渠道 + 物流类型 + 目的省 + 目的市 + 目的区** 校验（目的市、区为空时，空值参与比较）。

1. 当前文件内两行唯一键相同，则两行均导入失败，失败原因：文件内存在相同唯一键
2. 与库中已有记录唯一键相同，则导入失败，失败原因：已存在相同的物流费率，请勿重复保存

**启用互斥**

仅本条是否启用=启用时校验。按 **始发地 + 订单渠道 + 目的省 + 目的市 + 目的区** 查询当前文件内其他启用行，以及库中其他启用记录（不限承运商）：

1. 本条金额计费，且同线路已有启用重量计费，则导入失败，失败原因：同一配送仓、订单渠道、目的地不可同时启用重量计费与金额计费
2. 本条重量计费，且同线路已有启用金额计费，则导入失败，失败原因：同一配送仓、订单渠道、目的地不可同时启用重量计费与金额计费
3. 本条金额计费，且同线路已有另一条启用金额计费，则导入失败，失败原因：同一配送仓、订单渠道、目的地只能启用一条金额计费
4. 本条常温，且同线路已有另一条启用常温，则导入失败，失败原因：同一配送仓、订单渠道、目的地只能启用一条常温重量计费
5. 本条冷链，且同线路已有另一条启用冷链，则导入失败，失败原因：同一配送仓、订单渠道、目的地只能启用一条冷链重量计费

是否启用=禁用的行不参与本段校验。

## 9. 下单匹配、计算与预警（UC04）

### 9.2 匹配规则

1. 只匹配是否启用=启用的记录；费率启用即可，不因仓库/承运商后来禁用而排除
2. 按配送仓 + 订单渠道，目的地从细到粗：区 → 市 → 省 → 全国（目的省=全国且市、区为空）
3. **不按费用方案优先**。某一档存在启用费率即确定整单费用方案（该档因启用互斥只会是金额计费或重量计费），不再改用更粗档的另一种方案
4. 承运商不作为匹配入参，由匹配结果返回。重量计费时常温、冷链可返回不同承运商；金额计费只返回一个承运商
5. **金额计费**：用确定方案的那一档，整单只算一次
6. **重量计费**：常温、冷链分开匹配，各自按区 → 市 → 省 → 全国查找启用的重量计费（可不同目的地粒度、不同承运商）；只找重量计费，不改走更粗档的金额计费。某侧从区到全国都没有，则该侧匹配失败。同一物流类型启用最多一条，匹配不因多家承运商判重
7. 预警中金额计费物流类型带「不区分」，重量计费按常温或冷链带出，不另作匹配入参

重量计费谁算：

- 常温重量 >0，或常温、冷链重量均为 0：匹配并计算常温
- 冷链同理
- 仅一侧为 0、另一侧 >0：为 0 的一侧不算

匹配不到仍拦截下单，并按 [§9.6](#96-预警) 触发预警。

### 9.3 重抛比与计费重量

1. 重抛比 A:B 表示 A 吨货物对应 B 立方米，即 A×1000 kg : B CBM。例：1:3 表示 1000kg : 3CBM
2. 体积重量(kg) = 长(cm) × 宽(cm) × 高(cm) ÷ (1000 × B / A)。1:3 时除数为 3000
3. 计费重量 = max(订单重量, 体积重量)，保留 3 位小数；费率未配置重抛比，或该类型长、宽、高任一为 0 或不传时，计费重量=订单重量，不做抛重
4. 常温、冷链使用各自的重量与长宽高，分别计算计费重量

### 9.4 计算公式

金额均四舍五入到分。增值、上楼不乘折扣。配置了保价/派送就每单都加，调用方不必再传是否保价/是否派送。

**重量计费基础运费**

- 先按 [§9.3](#93-重抛比与计费重量) 算计费重量，再按计费重量命中阶梯档（左闭右开 [起始, 结束)，最后一档 [起始, ∞]）
- 计费重量 ≤ 该档首重重量：基础运费=该档首重价
- 计费重量 > 该档首重重量：基础运费=该档首重价 + 该档续价 × (计费重量 − 该档首重重量)
- 常温、冷链重量均为 0：不做抛重；基础运费=第一档首重价；不拦截

**金额计费基础运费**

- 两侧重量未同时为 0：用订单实付金额落档（边界同上），基础运费=该档固定运费，与订单重量无关
- 实付金额未传：拦截「请提供订单实付金额」
- 常温、冷链重量均为 0：基础运费=第一档固定运费（不按实付重新落档）
- 重量只用于上楼费和报表（订单重量、体积为常温+冷链加总）；报表 1 行，物流类型=不区分

**折扣、增值、上楼**

| 项 | 规则 |
| --- | --- |
| 客户侧基础应收 | 基础运费 × 运费折扣 |
| 结算侧基础应付 | 基础运费 × 结算折扣 |
| 保价费 | 增值服务=是且配置保价：max(最低价, 订单应付金额 × 费率%)，每单都加；应付未传拦截「请提供订单应付金额」 |
| 派送费 | 增值服务=是且配置派送：金额(每票)，每单都加 |
| 上楼费=否 | 0 |
| 上楼费=是 | 计费重量 ≤ 免上楼重量 → 0；楼层=1 → 0；否则按有无电梯：基础费 + 重量系数×计费重量 + 楼层系数×楼层数（件数不参与） |
| 上楼计费重量 | 重量计费按该侧计费重量；金额计费=常温计费重量+冷链计费重量（各自先按 [§9.3](#93-重抛比与计费重量)，未传侧为 0）；两侧均为 0 时按 0 |
| 楼层数 | 2 楼按 2 层、3 楼按 3 层；负 1 层按 2 层、负 2 层按 3 层，以此类推 |

**加总**

- 重量计费该类型客户运费 = 客户侧基础应收 + 保价费 + 派送费 + 上楼费；该类型结算同口径；整单客户运费=常温+冷链；结算按承运商分别返回（相同则加总为一条）
- 金额计费：整单只加一次增值与上楼；客户运费、结算均为整单一条

### 9.5 拦截与提示

| 条件 | 提示 | 预警 |
| --- | --- | --- |
| 区到全国都没有启用费率 | 未匹配到物流费率 | 未匹配到费率 |
| 整单已定为重量计费、需计算常温，且常温从区到全国都没有启用重量计费 | 未匹配到常温物流费率 | 未匹配到费率 |
| 整单已定为重量计费、需计算冷链，且冷链从区到全国都没有启用重量计费 | 未匹配到冷链物流费率 | 未匹配到费率 |
| 同一粒度同一物流类型命中多条启用费率 | 物流费率配置重复，请检查 | — |
| 金额计费且实付金额未传 | 请提供订单实付金额 | — |

预警不替代拦截，该拦截的仍拦截。

### 9.6 预警

以下情形触发系统预警（可同时多条原因）。

| 原因 | 触发条件 |
| --- | --- |
| 重量为0 | 重量计费：该物流类型参与计算且订单重量=0（含常温、冷链均为 0 而取第一档）。金额计费：常温重量与冷链重量均为 0 |
| 体积为0 | 仅重量计费：该物流类型参与计算，且长、宽、高任一为 0 或不传。金额计费不报体积为 0 |
