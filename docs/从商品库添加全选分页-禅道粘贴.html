从商品库添加 · 全选与分页

版本v1.1日期2026-09-11状态已落地原型

入口：商城商品、代采商品、直播排品、秒杀活动「从商品库添加」抽屉。共用同一套抽屉，规则一次生效。

可添加条件不变：仅售卖中、未加入过、选品库可售。待售卖、已添加、不可选商品不进全选范围。

1. 工具条

搜索框右侧加「全选」，一键作用于当前类目+搜索下全部页可添加商品，不限当前页。

勾上：当前筛选下全部页可添加都选中；取消：只清当前筛选里可添加的选中，其它类目或其它搜索条件下已选保留。

勾选态：当前筛选可添加全部已选为勾上；一部分已选为半选；一个都没有为未勾。没有可添加时禁用。

「共 N 件」按当前类目+搜索后的全部可展示件数计，靠右。

换类目、改搜索：页码回到第 1 页。已选商品跨页、跨筛选保留，直到取消勾选、点取消或关闭抽屉。

2. 底部分页

每页条数：20 / 50 / 100，默认 20。改条数回到第 1 页，已选保留。

页码、上一页 / 下一页、前往第 N 页。超出总页数按末页处理。翻页不改变已选，全选勾选态仍按全部页可添加是否都已选刷新。

3. 本期不做

不改可添加口径、不改确认添加后的写入规则。
