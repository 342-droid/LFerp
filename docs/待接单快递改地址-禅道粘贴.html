零售客户端 / 丰银宝 APP · 待接单快递单修改收货地址

版本v1.0日期2026-09-07状态待评审

已付款、仍为「待接单」的快递订单，用户可改收货地址。订单详情地址卡片增加「修改」，底栏增加「修改地址」，均进入「修改地址」页。地址簿页本身不改。

1. 范围

在范围内不在范围内
零售客户端（冷丰鲜选）、丰银宝 APP（进货 / 代采） 地址簿列表页改版（搜索、批量删除、新建入口保持原样）
履约：零售快递到家、代采快递到店 门店自提、仓配 / 平台配送
对客主状态 = 待接单（已付、截单前 / 未接单） 待发货及以后改地址；后台代客改地址
待付款快递单：详情卡片可出「修改」，进同一修改地址页（底栏仍是取消 / 付款） 支付后自动截单、跳过待接单直接待发货的单（按已接单，不能改）

2. 口径

项规则
能否改商家接单前（待付款、待接单）可改；商家接单后不可再改
改几次接单前可反复修改，不限制「付款后只能改一次」
价格只能原价修改。新地址导致运费变化则提交失败，不改价、不补差
截止点以订单对客主状态离开「待接单」为准（含截单成功进入待发货、提前发货补截单）
整单按订单头地址改，不按商品行拆地址

3. 订单详情入口

仅当：快递单，且状态为待接单（零售待付款卡片也可出「修改」）。

位置展示点击
收货地址卡片「修改>」与电话同一行、右对齐进入修改地址页
底栏（待接单）「修改地址」在「取消订单」左侧，均为描边按钮进入同一修改地址页

接单后（待发货及以后）：两个入口都消失。自提单、仓配单不展示本能力。

4. 修改地址页

4.1 结构

区块内容
导航返回 + 标题「修改地址」。无右上角「…」、无红点数字
说明条修改后会影响物流时效、送货上门等服务，只能原价修改。商家接单后不可再改。若因商品换仓、已发货、运费变更等原因导致修改失败，请您谅解。
原地址只读。展示当前订单收货地址：省市区、详细地址、姓名、完整 11 位手机号。仅此处打「默认」标，全页只有这一个默认标
选择新的收货地址复用地址簿数据。列表不出现与原地址相同的那条。每条：省市区、详细地址、姓名、完整 11 位手机号；右侧铅笔进入原有「编辑地址」
底栏橙色「提交修改」

电话一律展示连续 11 位数字，不打码、不空格分隔。本页不提供「新建地址」「批量删除」；新建 / 维护仍走地址簿原功能。

返回：回到进入时的订单详情，不改地址。

4.2 选择与提交

点列表一条即选中。必须另选一条与原地址不同的地址，再点「提交修改」。

提交成功：回订单详情，地址卡片立即更新为新地址；底栏「修改地址」仍在（接单前可再改）。

成功后写订单收货地址，记一条订单日志（操作人 = 用户，内容含改前 / 改后地址）。不通知短信。商家侧下次拉单看到新地址。

5. 提示文案

5.1 页内校验（提交前，不调接口）

场景文案
未选择新地址请选择新的收货地址
选中的仍是原地址请选择与原地址不同的收货地址
列表剔除原地址后为空暂无可用地址

5.2 提交失败（接口返回，Toast）

失败不改订单地址，用户留在修改地址页。按原因只出一条：

原因文案
商家已接单 / 已截单 / 对客已是待发货（含用户停在本页期间接单）商家已接单，无法修改地址
已发货或已有运单订单已发货，无法修改地址
改址导致换仓商品已换仓，无法修改地址
改址导致运费变化（不能原价）修改后运费发生变化，无法按原价修改
新地址缺省市区 / 详细地址 / 联系人或手机号不是 11 位收货地址无效，请重新选择
存在处理中售后订单存在处理中售后，暂无法修改地址
其它系统异常修改失败，请稍后重试

失败后若订单已离开待接单：返回详情时「修改」「修改地址」入口不再展示。

5.3 提交成功

场景文案
改址成功地址已修改

7. 验收

  • [ ] 零售、丰银宝待接单快递详情：卡片「修改>」与电话同行右对齐；底栏「修改地址」在「取消订单」左侧
  • [ ] 两个入口都进入「修改地址」页；返回不改地址
  • [ ] 接单前可改两次及以上，每次成功详情地址更新
  • [ ] 商家接单后入口消失；停留在修改页再提交 →「商家已接单，无法修改地址」
  • [ ] 已发货 / 换仓 / 运费变化 / 地址无效 / 处理中售后：分别出 §5.2 对应文案，地址不变
  • [ ] 列表不含原地址；电话 11 位不打码；「默认」只在原地址出现一次
  • [ ] 地址簿页功能不变
  • [ ] 自提、仓配、支付后自动截单进待发货的单：无改址入口
