库存管理规则（底层逻辑）

v1.0 · 2026-09-03 · 不在原型单独做库存台账 · 全文见 docs/库存管理规则-v1.0-20260903.txt

预占只在支付成功增加，按仓拆成现货预占 / 预售预占。截单不碰库存。核销才扣仓实物。直发可以没有仓总库存。

和原图的差异

  • 账本在配送仓，不是单店池；代采 / 商城 / 直播共享。
  • 先销后采为主，仓里可以还没有货。
  • 同一 SKU 可同时现货 + 预售；可售按现货百分比溢出的部分走预售预占。
  • 零售快递到家经常直发，不能套「总库存 − 预占 = 现货」。
  • 待支付不加预占。

公式

仓可用现货 = max(0, 仓实物 − 现货预占)
还能卖     = max(0, 仓可售 − 现货预占 − 预售预占)

支付数量 Q：
  走现货 = min(Q, 仓可用现货, 还能卖)
  走预售 = Q − 走现货
不足则拒单

预占增加

支付成功是唯一正向入口。一笔单可同时拆出现货段和预售段，用户不用先选预售。

直播先扣本场配额，再按上面拆段。配额和其他渠道抢同一仓「还能卖」。

履约

  • 零售快递到家：仓发走现货段；直发 / 无实物 / 溢出走预售段。直发核销不扣仓实物。
  • 零售自提、代采配送/快递：有仓可用现货走现货段，先销后采走预售段，到货后预售预占转现货预占。
  • 直播快递/自提：先占场次配额，再拆段。

节点

  • 支付：加预占
  • 截单：不动库存
  • 入库：实物 +N；预售预占转现货预占
  • 取消（未到手）：原路退预占
  • 出库：预占仍在（用户未到手）；本期出库不扣实物
  • 核销：清预占；非直发扣仓实物
