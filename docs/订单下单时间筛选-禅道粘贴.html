零售 / 代采订单 · 下单时间筛选

版本v1.1日期2026-09-11状态已落地原型

入口：零售订单、代采订单筛选区。直播订单列表本期不动。

下单时间独立占筛选区最上一行：左侧日期区间，右侧快捷项。必填，未选区间点查询提示「请选择下单时间」。

1. 区间展示

圆角输入框，日历图标在右侧。起止精确到时分秒：开始日 00:00:00，结束日 23:59:59，中间用「-」连接，如 2026-09-05 00:00:00 - 2026-09-11 23:59:59。

2. 快捷项

文字单选，从左到右：今天、昨天、近7天、近14天、近30天、上个月、本月。无勾选框。默认近7天，打开页面即回填区间。

选中态：文字与底部短下划线均为红色（#ff4d4f）。未选为深灰。点某一项立刻回填区间；已选项再点一次不取消（必须换一项或改日期）。

近 N 天含今天，共 N 个自然日（近7天 = 今天往前共 7 个自然日）。今天 / 昨天为单日，开始=结束。

本月：当月 1 日 00:00:00 至当月最后一天 23:59:59。上个月：上月 1 日 00:00:00 至上月最后一天 23:59:59。

3. 手改日期

结束日早于开始日时，按起止对调后再筛。

手改后的区间若与某个快捷项的自然日完全一致，自动点亮该项；对不上则全部取消选中，区间仍按手填值查询。

4. 展开 / 查询

下单时间始终露在首行，不随「展开/收起」藏进附加区。个人视图不能把「展开」藏掉，也不能强开 extra 区。

查询按闭区间筛下单日。重置回到默认近7天。

5. 本期不做

直播订单列表不加这套快捷项。不改导出、不改列表列。不再提供近3天、近15天。
