门店名称 / 简称 与 站点储位回写

版本v1.0日期2026-09-10状态已落地原型

涉及：添加门店、入驻审核编辑、门店档案列表、站点列表。一条链路：门店名称 → 门店简称 → 站点储位名称；站点改储位后再回写门店简称。

1. 入驻审核 / 添加门店

入驻审核编辑里原「入驻方名称」改为门店名称。保存后回写列表「入驻方名称」列（列名可仍叫入驻方名称，值=门店名称）。

门店简称 = 当时的门店名称，只读，不可手改。改门店名称时，若站点还没回写过储位，简称跟着变。

该简称传到对应站点的储位名称。储位编码默认用门店编码。

2. 站点改储位

站点列表增加「储位编码」「储位名称」。改完后回写门店档案简称 = 储位编码-储位名称。

站点一旦回写过，门店侧简称锁定为储位拼接值，不再跟门店名称连动。

3. 不回溯

已生成的入驻审核单不随站点回写变。站点回写只改门店档案简称，不改历史审核单上的名称。

4. 本期不做

不开放门店简称手填。不改门店编码生成规则。
