订单导出字段迭代

版本v1.1日期2026-09-09状态已落地原型

入口：零售订单、代采订单「导出订单」。粒度与生产一致：一个 SKU 一行，本期不改拆行。

只补字段和金额口径。导出清分明细、直播订单列表、列表表头本期不动。直播单、商城单都走零售订单，同一套导出。

列表没有的字段标「列表外」，可勾选一并导出，默认勾选。

1. 本次字段

原「实付金额」拆成两列；其余为新增。代采没有订单场景 / 直播场次，不导出「直播场次」。

字段类型位置谁有取值
实付金额（不含运费） 原「实付金额」拆出 列表内 零售、代采 订单实付去掉运费后，按该行商品金额占整单商品金额的比例分摊。末行吃分毫尾差，不再把整笔运费叠进最后一行实付。
实付金额（含分摊运费） 原「实付金额」拆出 列表内 零售、代采 该行「实付金额（不含运费）」+ 该行「分摊运费」。
商品编码 新增 列表外 零售、代采 该行 SKU 编码。无值「—」。
商品类目 新增 列表外 零售、代采 有档案类目用档案；没有则按品名归到选品库类目（水产海鲜 / 肉禽蛋品 / 时令水果 / 乳品烘焙 / 新鲜蔬菜 / 粮油调味 / 酒水饮料 / 其他）。
分摊运费 新增 列表外 零售、代采 本单运费按该行商品金额比例分摊，末行吃尾差。无运费 0.00。
退款金额 新增 列表外 零售、代采 该行已完成的商品售后退款 + 按同样比例分摊的已退运费。待审批、退款中等处理中金额不计入。无退款 0.00。
直播场次 新增 列表外 仅零售 该单所属直播场次名称。商城单或无场次为「—」。

2. 金额关系

实付金额（含分摊运费）＝ 实付金额（不含运费）＋ 分摊运费。

验一笔：牛腩单实付 25、运费 10、已退运费 4 → 不含运费 15.00，分摊运费 10.00，含分摊运费 25.00，退款金额 4.00。

3. 本期不做

不改「一 SKU 一行」。不改导出清分明细。不改直播订单列表。列表不增加「商品编码 / 商品类目 / 分摊运费 / 退款金额 / 直播场次」列，只在导出里给。
