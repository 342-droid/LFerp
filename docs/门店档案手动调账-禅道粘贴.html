门店档案 · 手动调账

版本v1.0日期2026-09-11状态已落地原型

入口：门店详情 → 账户信息。保证金账户、余额账户的「余额」旁各有【手动调账】。保证金原【解冻】保留。

资金性质：平台基本户 ↔ 所选门店账户划拨。增加：平台基本户 → 所选账户入账。减少：所选账户出账 → 平台基本户。

不受货款不可提现、在途、冻结占用限制，按该账户账面全额可调减。保证金按保证金余额可调减。

1. 弹窗

字段规则
账户余额账户 / 保证金账户。从哪边点进来预填哪边，可改。
调账方向增加 / 减少。默认增加。切换后刷新原因枚举和划拨路径。
调账金额必填，> 0，两位小数。
调账原因必填。取「账户 × 方向」账变类型单选 +「其他」。选其他必须写具体原因。
备注选填，最多 100 字。
图片 / 视频选填。图片最多 9 张，jpg/png/gif/webp，单张 ≤ 2MB。视频最多 1 个，mp4/mov，≤ 20MB。超限或格式不对不可传。

取消 / 关窗不落账。确认校验通过后改余额并写一条账变。

2. 调账原因枚举

账户增加减少
余额账户 首次充值、佣金结算、充值、提现回退、退款、保证金解冻 提现、进货支付、售后/责任类扣款、佣金回退、保证金补缴
保证金账户 保证金入账、保证金补缴 售后/责任类扣款、保证金解冻

每组另加「其他」。选其他：账变类型落「其他(具体原因)」（如「其他(店庆补贴)」），具体原因不进说明列。

3. 账变记录

确认后即时入账变：账户类型=所选账户，资金方向=划拨，资金来源/去向=平台基本户，账变类型=所选原因（其他见上），金额按增 + / 减 −，操作人=当前后台账号（姓名 / 账号）。

说明列只放备注 + 图片/视频。无备注无附件为「—」。图片、视频可点击放大查看，视频放大后可播放。

筛选项「账变类型」增加【其他】。所有「其他(具体原因)」都归这一项，列表显示如「其他(店庆补贴)」。

门店 APP 钱包账户明细同一条流水按划拨、交易方=平台基本户展示；筛「其他」同样归并。

4. 本期不做

不做出双分录（不自动对打另一边钱包）。不改解冻、账户配置、充值提现原规则。附件不落生产对象存储（原型会话内回显）。
