代采商品 · 售卖规格限购

版本v1.0日期2026-09-10状态已落地原型

入口：代采商品添加 / 编辑抽屉 → 每个已选 SKU 的售卖规格。按 SKU 配，不按 SPU 统一一条。

默认「不限购」。旧值「每用户限购」按「每单限购」读。

1. 枚举

选项含义限购数量
每单限购同一订单该 SKU 最多买 N展示，必填正整数
每天限购同一买家当天该 SKU 最多买 N展示，必填正整数
累计限购同一买家历史合计该 SKU 最多买 N展示，必填正整数
不限购不限制购买件数不展示；已填数量不参与限购

切到限购三项时，下拉右侧出现「限购数量」。切回不限购，数量框隐藏。

2. 同步与保存

「同步至其他 SKU」含限购配置、限购数量，规则与其它售卖规格字段相同：只覆盖已选 SKU，未选不动。

随商品保存落库。未选限购三项时按不限购存。

3. 本期不做

列表不增加限购列。不做 C 端下单拦截（配置先落后台）。不改秒杀 / 积分商城 / 直播排品已有限购。
