## 口径（后文不再重复）

两个按钮各导出一种表，不要混：

| 按钮 | 一行是什么 | 文件中心任务 |
| --- | --- | --- |
| 导出订单 | 一条订单 | 订单列表导出 |
| 导出订单清分明细 | 一条清分项 | 订单清分明细导出 |

勾选框共用。先勾订单，再决定导出哪一种表。

清分明细的数据口径与订单详情「清分明细」一致：支付成功后生成；未配门店佣金比例时仍有供应商/平台项，不生成门店/商户项。

## 1. 入口

零售订单、代采订单列表工具栏，并排两个按钮。

零售原「导出」改名为「导出订单」，右侧新增「导出订单清分明细」。代采同样。

直播订单列表本期不做。

---

## 2. 导出订单

沿用原导出弹窗，只改按钮文案。

范围：勾选数据 / 当前查询全部。字段仍是列表列 + 列表外（收货地址、售后状态）。确定后提交「订单列表导出」，到文件中心下载。

未勾选却选「勾选」→ 提示先勾选。查询无单 → 提示无数据。

---

## 3. 导出订单清分明细

弹窗结构与「导出订单」相同：范围 + 字段 + 全选，标题为「导出订单清分明细」。勾选过的字段下次记住。

### 3.1 范围

| 选项 | 取哪些订单 |
| --- | --- |
| 导出勾选数据 | 当前查询里已勾选的订单 |
| 导出所有查询数据 | 当前筛选结果全部订单 |

默认：有勾选用勾选，否则用全部查询。

范围内先按订单取清分，再拆成清分项行。提示条数按清分项计，不按订单计。

### 3.2 一行怎么拆

优先用订单详情的 SKU 清分表：每个 SKU 下每一条收款方记录一行。

没有 SKU 表、但有门店明细且已配门店佣金比例：一门店明细一行。

该单无清分（未支付、或详情为空）→ 该单不产出行。范围内一行都没有 → 不提任务，提示「所选订单暂无清分明细可导出」。

### 3.3 导出字段

默认全选。列表内字段与详情清分表对齐：

| 字段 | 说明 |
| --- | --- |
| 订单号 | 所属订单 |
| 订单状态 | 待支付 / 待发货 / 交易成功等 |
| 订单场景 | 直播 / 商城；代采可空 |
| 商品名称 | SKU 名称；门店明细行可空 |
| 商品规格 | 该 SKU 规格 |
| 商品编码 | SKU 编码 |
| 商品数量 | 该 SKU 下单数量 |
| 实付 | 该 SKU 实付 |
| 售后金额 | 该 SKU 已退/在退金额 |
| 净实付金额 | 实付 − 售后金额 |
| 售后状态 | 订单售后汇总状态（退款中 / 已完成等） |
| 角色分佣 | 该 SKU 角色分佣合计 |
| 供应商采购成本 | 采购价 × 售卖系数 × 下单数量 |
| 毛利率 | 该 SKU |
| 收款方 | 平台 / 商户 / 门店 / 供应商等 |
| 角色 | 收款方角色 |
| 账户 | 收款账户（脱敏展示） |
| 分佣方式 | 如按比例、采购成本 |
| 命中策略 | 结算策略名称；是否默认策略一并带出 |
| 应收 / 实收 | 该清分项金额 |
| 清分状态 | 待清分 / 已清分 |
| 结算状态 | 待结算等 |
| 入账状态 | 待入账等 |

列表外、可勾选一并导出：订单渠道（如下单端小程序）、下单门店、通道流水（收款明细里的通道侧流水，不是列表「支付流水」）。

### 3.4 提交之后

通过校验后提交文件中心任务「订单清分明细导出」。

| 页面 | 文件名前缀 |
| --- | --- |
| 零售订单 | 零售订单清分明细_日期 |
| 代采订单 | 代采订单清分明细_日期 |

提示：已提交导出勾选/查询数据（N 条清分明细，M 个字段），请到文件中心下载。

## 4. 校验一览

| 情况 | 结果 |
| --- | --- |
| 未选任何导出字段 | 请至少选择一个导出字段 |
| 范围=勾选且未勾订单 | 请先勾选要导出的订单 |
| 范围=查询且当前无单 | 当前查询无数据可导出 |
| 范围内订单都没有清分项 | 所选订单暂无清分明细可导出，不生成任务 |
