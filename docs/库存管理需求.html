一、背景与目标

代采、商城、多场直播共用配送仓现货。仓现货既有先采后销（已入库再卖），也有先销后采（先卖再补货）。运营在各渠道编辑商品 → 售卖规格配置看现货、配可售、看本渠道预占。

可售和预占必须在同一维度，才能干净地算剩余可售。这个维度是放单渠道：代采 / 商城 / 直播 / 零售。各渠道各自独立，不摊到仓，不加总。

预占对外只叫预占库存。支付成功后本渠道 +Q，按履约节点本渠道 −Q。履约方式（自提 / 快递 / 配送）只决定何时释放，不再把预占记到门店、配送仓或直发账。

进销方式货在哪支付入库
先采后销仓里已有实物本渠道预占 +Q仓实物 +N，预占不动
先销后采仓里还没有，或可售超出实物本渠道预占 +Q仓实物 +N，预占仍锁着，直到履约节点释放
直发不经过仓实物账本渠道预占 +Q不加仓实物

二、术语

术语定义
放单渠道下单占用可售的渠道：代采 / 商城 / 直播 / 零售。可售、预占都记在这里。
仓实物 / 现货仓储按配送仓维护的在库数量。入库加。直发可以没有。
可售库存本渠道该 SKU 的可卖上限。代采页=代采可售，商城页=商城可售。直播不配可售：页上只读，按现货算出，用来卡本场配额。没有中央可售账本。
预占库存本渠道已支付、尚未按履约节点释放的数量。与可售同一维度。页面只展示这一个数。
剩余可售max(0, 本渠道可售 − 本渠道预占)。直播本场配额从这里切。
仓可用现货仓实物。预占不锁仓（先销后采允许可售超出实物）。直发不碰仓实物。

三、账本维度

项规则
现货SKU × 配送仓。仓储按仓维护，仓店表只展示这一列
可售库存SKU × 放单渠道。写在规格卡
预占库存SKU × 放单渠道。写在规格卡，与可售并列
剩余可售同一渠道上的减法，不跨渠道、不摊到仓
门店现货继承所属仓，不另建现货账，不另建预占账
不再按「门店预占 / 仓预占 / 直发预占」建账。履约节点只用来触发本渠道预占 −Q。

四、可售、预占与仓店表（原型）

字段谁改规则
现货库存只读各配送仓实物之和
可售 · 按现货库存代采 / 商城可改填百分比。100% 取现货；大于 100% 多卖的部分仍记入本渠道预占
可售 · 按具体数量代采 / 商城可改本渠道该 SKU 的件数上限，不按仓分摊、不与其它渠道加总
预占库存只读本渠道该 SKU 已支付未释放的数量
剩余可售只读本渠道可售 − 本渠道预占
本场售卖配额仅直播可改不超过剩余可售（含本场已占）。保存不回写中央商品库
仓店现货只读默认收起。列：配送仓 / 门店 / 现货。不展示可售、不展示预占
公式计算
本渠道可售（按现货）round(各仓现货合计 × 百分比 / 100)
本渠道可售（按数量）运营填写的本渠道件数上限
本渠道预占该放单渠道已支付未释放之和
剩余可售max(0, 本渠道可售 − 本渠道预占)
仓可用现货仓实物。预占不扣仓

五、预占何时加减

唯一加预占入口：支付成功。待支付、关未付、草稿、截单都不占货。

支付数量 Q：本渠道剩余可售不够则整行拒单；够则本渠道预占 +Q。直播先扣本场配额。

履约走仓储？预占记在哪何时本渠道预占 −Q
零售 × 门店自提货在店/仓零售渠道用户核销后（同时扣仓实物）
零售 × 快递到家不走仓储，供应商直发零售渠道供应商发货后
商城 × 快递 / 自提快递不走仓储商城渠道快递：供应商发货后；自提：用户核销后
代采 × 平台配送仓发到店代采渠道门店收货后
代采 × 快递配送不走仓储，供应商发到店代采渠道门店收货后（收尾）
直播 × 自提同零售自提直播渠道用户核销后
直播 × 快递不走仓储，供应商直发直播渠道供应商发货后
零售/直播快递供应商一发货就减，且不进仓储。代采配送、代采快递都以门店收货收尾。取消（未释放前）原路退本渠道预占。

六、冻结口径

议题决策
可售 / 预占维度同一维度：SKU × 放单渠道
预占展示规格卡只展示预占库存，页面不出现两类预占名称，也不按仓/店拆
预占何时加只在支付成功，加到下单那个放单渠道
预占何时减按履约节点从该渠道减，不是统一用户签收
零售自提记零售渠道；用户核销后 −Q，并扣仓实物
零售/商城/直播快递不走仓储；记对应渠道；供应商发货后 −Q
代采配送 / 代采快递都记代采渠道；门店收货后 −Q
截单不碰库存账
仓店表只展示现货；不展示可售、不展示预占
可售归属本渠道该 SKU，代采 / 商城 / 直播 / 零售各自独立
剩余可售本渠道可售 − 本渠道预占

七、验收

#验收项
1代采 / 商城 / 直播编辑：规格卡有现货、可售、预占、剩余可售；可售与预占都是本渠道该 SKU
2代采页预占 ≠ 商城页预占 ≠ 直播页预占；改一个渠道的可售不影响其它渠道预占
3仓店表列为配送仓 / 门店 / 现货，没有预占列；默认收起，合计只加现货
4可售在规格卡，是本渠道上限，不是仓字段、不是多渠道加总
5待支付不加预占；支付成功本渠道预占 +Q；该渠道剩余可售不够则拒单
6零售自提用户核销、快递供应商发货、代采门店收货，各自从对应渠道预占 −Q
7截单不改预占；取消（未释放前）退该渠道预占
