经营中心 / 佣金明细 · 下单日期与入账日期

版本v1.0日期2026-09-28状态已落地原型

两处同一套佣金口径，切换后汇总和下面的订单一起变。

页面入口开关文案
经营中心 门店 APP → 经营中心 下单日期 / 入账日期
佣金明细 门店档案 → 门店详情 → 佣金明细 下单日期 / 入账时间

「入账日期」和「入账时间」是同一个维度，只是两个页面的按钮用词不同。

1. 两个口径

下单日期入账日期 / 入账时间
含义预到账佣金实际到账佣金
按哪天归集下单日（支付日的日期）结算时间的日期
计入哪些单已生成门店清分、未关闭、结算未取消。含待结算、结算中、已结算、结算失败。仅结算状态为「已结算」，且写了结算时间。
提示文案预到账佣金实际到账佣金
累计标题累计预到账佣金累计实际到账佣金
时段后缀今日 / 昨日 / 本周 / 本月预到账今日 / 昨日 / 本周 / 本月到账

预到账是「按下单日统计的门店佣金」，已入账的单、结算失败的单都算在对应下单日里。实际到账只认已经结算成功的单，待结算、结算中、结算失败都不进这个数。

2. 单笔金额与笔数

两套口径的单笔金额都叫所得佣金，算法相同，差别只在「算不算进这套口径」和「归到哪一天」。

情况所得佣金预到账实际到账
未配置门店佣金比例，无清分0，不记有效单不计入不计入
订单已关闭，或结算已取消0，不记有效单不计入不计入
待结算（实付 − 退款）× 门店佣金比例，随退款变。实付减退款小于 0 时按 0。计入下单日不计入
结算中金额锁死，取生成结算单时的金额计入下单日不计入
已结算金额锁死计入下单日计入结算日
结算失败仍按所得佣金公式计入下单日不计入

汇总上的金额、笔数只加有效单。同一天的预估佣金（经营中心按日分组标题）等于该日有效单所得佣金之和。

下单日和结算日可以不是同一天。一笔单在「下单日期」里出现在下单那天，在「入账日期」里出现在结算那天。

3. 汇总区

顶部汇总只跟当前口径有关，不跟下面列表的时段筛选联动。列表选「今天」时，累计、本周、本月仍是全量口径，不会收成当天。

项区间
累计该口径下全部有效单，不限日期
今日日期等于今天
昨日日期等于昨天
本周含今天往前共 7 个自然日（今天 − 6 天 ～ 今天）
本月当月 1 日 ～ 今天

这里的「本周」是滚动 7 天，不是周一到周日。「本月」是自然月，和列表里的「近 1 个月」不是同一个区间。

经营中心汇总在可提现余额下面：口径提示、累计金额和笔数、四个时段格。佣金明细汇总为两行：可提现账户余额 / 累计金额 / 单数，以及今日、昨日、本周、本月。

4. 经营中心订单列表

默认「下单日期」+「近 1 个月」。点「下单日期」或「入账日期」立刻重算汇总，并按同一口径重刷下面的订单。订单状态 Tab、搜索条件保留。

时段在列表上，点了即筛，不必再点查询。含今天，右端到今天：

时段区间
今天今天一天
昨天昨天一天
近 7 天含今天往前共 7 个自然日
近 1 个月含今天往前共 30 个自然日（今天 − 29 天 ～ 今天）。默认。

下单日期：按订单的下单日过滤、按天下组。组标题为「共 N 笔有效订单，预估佣金」。无清分、已关闭的订单如果下单日落在时段内，卡片仍可出现，但不进 N 和金额。

入账日期：只留下已结算且有结算时间的订单，按结算日过滤、按结算日分组。组标题为「共 N 笔有效订单，到账佣金」。没有结算日的订单不出现。空列表文案：「暂无符合条件的订单」。

订单状态仍可再筛：全部订单、待发货、待提货/待收货、已完成。搜索类型：手机号、订单编号、会员码、用户昵称、商品。

5. 佣金明细订单列表

口径、汇总算法与经营中心相同。差异只在列表形态。

切换「下单日期 / 入账时间」后立即重刷表格，页码回到第 1 页。第二列标题跟着变：下单日期，或入账时间。入账时间单元格展示结算时间；下单日期单元格展示下单日。

入账时间下列表去掉未入账的行。无数据时：「暂无已入账佣金」，说明「仅已结算并写入结算时间的订单计入实际到账」。下单日期无数据时：「暂无清分数据」。

时段用下拉，默认近 1 个月：全部、今天、昨天、近 7 天、近 1 个月、6 个月、近一年、自定义时间范围。今天 / 昨天 / 近 7 天 / 近 1 个月的天数与经营中心一致。6 个月、近一年按月回推到今天。全部不限起止。选快捷项会回填起止日期；点【查询】后按当前口径的日期筛选，并带上订单状态、关键词。重置回到下单日期、近 1 个月、全部状态，并清空关键词。

订单状态：全部、待发货、待收货、待提货/待收货、已完成、已关闭。关键词：手机号 / 订单号 / 会员码 / 昵称 / 商品。

6. 验收要点

操作期望
默认打开下单日期，提示「预到账佣金」。经营中心列表为近 1 个月；佣金明细时段为近 1 个月。
切到入账提示变为「实际到账佣金」。汇总只剩已结算单，并改按结算日。下面订单同步换成已入账的单，经营中心按结算日分组，佣金明细第二列改为入账时间。
切回下单日期汇总和列表都回到下单日。待结算、结算失败重新出现在对应下单日。
同一笔已结算单下单日、结算日不同时，两个口径里分别出现在两天，金额相同。
结算失败只出现在下单日期，不出现在入账日期。
无清分 / 已关闭 / 结算已取消两个汇总都不计金额、不计笔数。
列表改时段只改下面的订单。顶部累计、今日、昨日、本周、本月不变。
今天、昨天、近 7 天、近 1 个月每个时段都有订单可点。入账口径下，超出近 7 天、落在近 1 个月内的已结算单，只在近 1 个月出现。
