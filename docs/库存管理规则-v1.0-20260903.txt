## 一、背景与目标

### 1.1 背景

代采、商城、多场直播共用配送仓现货。仓现货既有先采后销，也有先销后采。零售/商城/直播快递经常是供应商直发，不进仓储。

v1.5 及更早：可售已经按渠道配，预占却拆在门店、配送仓、直发账上。剩余可售只能写成「本渠道可售 − 本渠道相关预占」，对不齐。

v1.6 起把可售和预占收到同一维度——放单渠道。履约方式只决定何时释放，不再决定预占记在哪。

### 1.2 目标

- 运营在各渠道「编辑商品 → 售卖规格配置」看现货、配本渠道可售、看本渠道预占和剩余可售。
- 剩余可售是同一渠道上的减法：本渠道可售 − 本渠道预占。
- 支付成功才占货；履约节点从该渠道释放；截单不碰库存。
- 仓店表只解释货在哪个仓、覆盖哪些店，不承担可售和预占。

### 1.3 发布逻辑

编辑商品规格卡先露出本渠道可售 / 预占 / 剩余可售 → 仓店表只留现货 → 订单支付/履约按放单渠道加减预占 → 截单、售后仍走各自 PRD，不另建库存账。

### 1.4 范围与优先级

| 优先级 | 内容 |
| --- | --- |
| P0 | 可售、预占按 SKU × 放单渠道；规格卡展示现货 / 可售 / 预占 / 剩余可售 |
| P0 | 支付加预占、履约释放、取消退占；剩余可售不够整行拒单 |
| P0 | 仓店表现货只读；直播本场配额不超过剩余可售 |
| 本期不做 | 选品库库存总表；仓储入库/盘点改版；零售独立可售配置页；在页面播放加减过程 |

## 二、用户与角色

| 角色 | 诉求 |
| --- | --- |
| 平台运营（代采 / 商城） | 在本渠道编辑商品里配可售上限，看本渠道预占和剩余可售，不跟其它渠道加总 |
| 直播运营 | 看只读可售和本渠道预占，本场配额不超过剩余可售；保存只作用于本场排品 |
| 用户 / 门店进货人 | 剩余可售不够不能付；付了之后按履约走，取消未履约前应退回可售 |
| 仓储 / 仓配 | 只维护配送仓现货；不按渠道拆仓账 |
| 研发 / 测试 | 维度、公式、加减节点可对照验收 |

## 三、术语与概念

| 术语 | 产品定义 |
| --- | --- |
| 放单渠道 | 下单占用可售的渠道。取值：代采 / 商城 / 直播 / 零售。可售、预占都记在这里。不是订单截单里的「订单渠道」（那边只有零售 / 代采） |
| 仓实物 / 现货 | 仓储按配送仓维护的在库数量。入库加。直发可以没有 |
| 可售库存 | 本渠道该 SKU 的可卖上限。代采页=代采可售，商城页=商城可售。直播不配可售：页上只读，按现货算出（默认 100%），用来卡本场配额。没有中央可售账本 |
| 预占库存 | 本渠道已支付、尚未按履约节点释放的数量。与可售同一维度。页面只展示这一个数 |
| 剩余可售 | max(0, 本渠道可售 − 本渠道预占)。支付和下单卡这个数 |
| 本场售卖配额 | 仅直播。本场最多能卖多少，不超过剩余可售（含本场已占）。不回写中央商品库 |
| 仓可用现货 | 等于仓实物。预占不锁仓。直发不碰仓实物 |
| 先采后销 | 仓里已有实物再卖。支付仍加本渠道预占，入库只加仓实物 |
| 先销后采 | 仓里还没有、或可售超出实物。支付先占可售，货后到，预占仍锁到履约节点 |
| 直发 | 供应商发货，不经过仓实物账。预占仍记在放单渠道 |

不要再用「现货预占 / 预售预占」「门店预占 / 仓预占 / 直发预占」对外说话。对内实现也不再按这些建账。

## 四、账本维度与放单渠道

### 4.1 两本账

| 项 | 维度 | 写在哪 |
| --- | --- | --- |
| 现货 | SKU × 配送仓 | 仓店表；规格卡现货=各仓之和 |
| 可售库存 | SKU × 放单渠道 | 规格卡 |
| 预占库存 | SKU × 放单渠道 | 规格卡，与可售并列 |
| 剩余可售 | 同一渠道上的减法 | 规格卡；不跨渠道、不摊到仓 |
| 门店现货 | 继承所属仓 | 不另建现货账，不另建预占账 |

### 4.2 放单渠道对照

| 放单渠道 | 编码 | 谁配可售 | 预占加在哪 | 常见履约（只决定何时减） |
| --- | --- | --- | --- | --- |
| 代采 | proxy | 代采编辑商品 | 代采渠道 | 平台配送、快递配送 → 门店收货后 −Q |
| 商城 | mall | 商城编辑商品 | 商城渠道 | 快递：供应商发货后 −Q；自提：用户核销后 −Q |
| 直播 | live | 不配，只读（按现货） | 直播渠道 | 同零售：自提核销 / 快递发货 |
| 零售 | retail | 本期无独立配置页，可售默认按现货 | 零售渠道 | 自提：用户核销后 −Q（同时扣仓实物）；快递：供应商发货后 −Q |

四个渠道各自独立。代采页预占 ≠ 商城页预占 ≠ 直播页预占 ≠ 零售预占。改一个渠道的可售，不影响其它渠道的预占。

## 五、原型：可售、预占与仓店现货

原型入口：代采 / 商城「编辑商品 → 售卖规格配置」；直播「排品编辑 → 售卖规格」。加减过程不在页面播放。

| 字段 | 谁改 | 规则 |
| --- | --- | --- |
| 现货库存 | 只读 | 各配送仓实物之和 |
| 可售 · 按现货库存 | 代采 / 商城可改 | 填百分比。100% 取现货；大于 100% 多卖的部分仍记入本渠道预占 |
| 可售 · 按具体数量 | 代采 / 商城可改 | 本渠道该 SKU 的件数上限，不按仓分摊、不与其它渠道加总 |
| 预占库存 | 只读 | 本渠道该 SKU 已支付未释放的数量 |
| 剩余可售 | 只读 | 本渠道可售 − 本渠道预占 |
| 本场售卖配额 | 仅直播可改 | 不超过剩余可售（含本场已占）。保存不回写中央商品库 |
| 仓店现货 | 只读 | 默认收起。列：配送仓 / 门店 / 现货。不展示可售、不展示预占 |

| 公式 | 计算 |
| --- | --- |
| 本渠道可售（按现货） | round(各仓现货合计 × 百分比 / 100) |
| 本渠道可售（按数量） | 运营填写的本渠道件数上限 |
| 本渠道预占 | 该放单渠道已支付未释放之和 |
| 剩余可售 | max(0, 本渠道可售 − 本渠道预占) |
| 直播本场配额上限 | 剩余可售 + 本场已占（= 直播可售 − 其它场次预占） |
| 仓可用现货 | 仓实物。预占不扣仓 |

## 六、预占何时加减

唯一加预占入口：支付成功。待支付、关未付、草稿、截单都不占货。

支付数量 Q：本渠道剩余可售不够则整行拒单；够则本渠道预占 +Q。直播先卡本场配额，再占直播渠道预占。

| 履约 | 走仓储？ | 预占记在哪 | 何时本渠道预占 −Q |
| --- | --- | --- | --- |
| 零售 × 门店自提 | 货在店/仓 | 零售渠道 | 用户核销后（同时扣仓实物） |
| 零售 × 快递到家 | 不走仓储，供应商直发 | 零售渠道 | 供应商发货后 |
| 商城 × 快递 / 自提 | 快递不走仓储 | 商城渠道 | 快递：供应商发货后；自提：用户核销后 |
| 代采 × 平台配送 | 仓发到店 | 代采渠道 | 门店收货后 |
| 代采 × 快递配送 | 不走仓储，供应商发到店 | 代采渠道 | 门店收货后（收尾） |
| 直播 × 自提 | 同零售自提 | 直播渠道 | 用户核销后 |
| 直播 × 快递 | 不走仓储，供应商直发 | 直播渠道 | 供应商发货后 |

零售/直播快递供应商一发货就减，且不进仓储。代采配送、代采快递都以门店收货收尾。取消（未释放前）原路退本渠道预占。截单只改履约承诺，不加不减预占。

### 6.1 进销方式

| 进销方式 | 货在哪 | 支付 | 入库 |
| --- | --- | --- | --- |
| 先采后销 | 仓里已有实物 | 本渠道预占 +Q | 仓实物 +N，预占不动 |
| 先销后采 | 仓里还没有，或可售超出实物 | 本渠道预占 +Q | 仓实物 +N，预占仍锁着，直到履约节点释放 |
| 直发 | 不经过仓实物账 | 本渠道预占 +Q | 不加仓实物 |

## 全链路库存加减

| 节点 | 仓实物 | 本渠道预占 | 仓可用现货 | 剩余可售 |
| --- | --- | --- | --- | --- |
| 待支付 / 关未付 | — | — | — | — |
| 支付成功 | — | +Q | — | −Q |
| 支付不够 · 拒单 | — | — | — | — |
| 截单 | — | — | — | — |
| 入库 / 备货到仓 | +N | — | +N | 随可售配置 |
| 取消（尚未释放） | — | −Q | — | +Q |
| 零售自提 · 用户核销 | −Q | −Q | −Q | 不加回 |
| 零售/商城/直播快递 · 供应商发货 | —（不走仓储） | −Q | — | 不加回 |
| 代采配送 · 门店收货 | — | −Q | — | 不加回 |
| 代采快递 · 门店收货 | — | −Q | — | 不加回 |
| 售后回库 | +回库 | — | +回库 | 不自动加 |

## 七、冻结口径

| 议题 | 决策 |
| --- | --- |
| 可售 / 预占维度 | 同一维度：SKU × 放单渠道 |
| 预占展示 | 规格卡只展示预占库存，不按仓/店拆 |
| 预占何时加 | 只在支付成功，加到下单那个放单渠道 |
| 预占何时减 | 按履约节点从该渠道减 |
| 零售自提 | 记零售渠道；用户核销后 −Q，并扣仓实物 |
| 零售/商城/直播快递 | 不走仓储；记对应渠道；供应商发货后 −Q |
| 代采配送 / 代采快递 | 都记代采渠道；门店收货后 −Q |
| 截单 | 不碰库存账 |
| 仓店表 | 只展示现货 |
| 可售归属 | 本渠道该 SKU，各自独立 |
| 剩余可售 | 本渠道可售 − 本渠道预占 |
| 直播配额 | 从直播渠道剩余可售里切，不另建可售账 |
| 零售可售配置 | 本期无独立页，默认按现货；预占仍记零售渠道 |
