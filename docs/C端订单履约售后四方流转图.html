1. 两级合并（多单 → 采购单）

零售仓配自提：先按门店截单并成 MDH，再按供应商/门店维度生成 PO。

多笔消费者订单 CO
    │  ① 截单：按【门店】合并
    ▼
门店订货单 MDH（一张可含多 CO、多 SKU）
    │  ② 生成采购单：按【供应商+收货地】或【门店+收货地+供应商】
    ▼
采购单 PO
    ├─► WMS 采购入库 IBD
    └─（截单当时并行）► WMS 仓配出库 OBD（±调拨）
步骤时机合并维度产出
① 截单门店订货汇总按门店MDH*，回写 CO
② 采购采购需求汇总供应商+收货地 / 门店+收货地+供应商PO*，回写 MDH.poNo

2. 支付成功后总览分叉

零售快递到家不进 MDH/PO；自提走完整采购+WMS。

flowchart TD
    A[C端下单拆单] --> B[支付]
    B -->|失败/超时| Z[订单关闭]
    B -->|成功·待发货| C{履约}

    C -->|零售·快递到家| E1[供应商备货发货]
    E1 --> E2[MDM上传快递单]
    E2 --> E3[消费者确认收货·完成]

    C -->|零售·门店自提=平台配送| M0[进入门店订货汇总池]
    M0 --> M1[①截单·按门店生成MDH]
    M1 --> M2[回写CO↔MDH]
    M2 --> P1[并行A·建仓配OBD]
    M2 --> P2[并行B·进采购需求汇总]
    P2 --> P3[②生成PO·合并MDH行]
    P3 --> P4[PO审核·建IBD入库]
    P1 --> W1[WMS出库先拣后分]
    P4 --> W1
    W1 --> S1[门店收货·待自提]
    S1 --> S2[门店核销·交易完成]

    C -->|代采·快递/平台配送| D0[同样进MDH截单链]
    D0 --> D1{履约}
    D1 -->|快递配送| D2[PO免审核·收货地=门店·无仓配OBD]
    D1 -->|平台配送| D3[同零售仓配·PO需审核]

6. 售后退货三落点

sequenceDiagram
    participant C as 消费者
    participant Plat as 平台
    participant Sup as 供应商
    participant Store as 门店
    participant WH as 仓库

    C->>Plat: 退货退款申请·审核通过
    alt 快递到家
        Plat-->>C: 退货地址=供应商
        C->>Sup: 寄回
        Sup->>Plat: 确认收货
        Plat->>C: 退款
    else 门店自提
        Plat-->>C: 退货地址=门店
        C->>Store: 退回门店
        Store->>Plat: 确认收货
        Plat->>C: 退款
    else 仓配进货
        Store->>Plat: 确认司机已取货
        WH->>Plat: 退货入仓
        Plat->>C: 退款
    end

8. UAT 一页操作清单（仓配自提）

#角色动作
1消费者user-app 下单支付（自提）
2平台订单零售订单 → 待发货
3采购门店订货汇总 → 截单（多 CO → MDH）
4采购门店订货单核对 MDH / relatedOrderNo
5采购采购需求汇总 → 生成采购单
6采购主管采购单审核通过
7仓库入库单采购收货
8仓库出库：集波→拣→分→复核→发货
9物流（跨仓）路由规则 / 调拨出库
10门店收货 → 扫码核销
11平台售后售后单/退款；补货再出「售后补送」MDH
