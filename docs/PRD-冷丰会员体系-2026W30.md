## 一、背景与目标

### 1.1 背景

冷丰业务已具备 C 端会员基础档案（原「C 端会员」），但运营侧缺少完整的**标签、分群、等级成长、积分**闭环：

- 无法按标签 / 消费 / 行为 / 偏好精细圈人，营销与运营依赖人工导出；
- 会员等级与成长值规则不可配置，C 端无法展示权益与成长进度；
- 积分抵现、兑换、消费送分缺少统一规则入口与流水查询。

本周在 ERP 原型中补齐「会员」一级能力，并打通 C 端会员中心展示链路。

### 1.2 目标

**业务目标**
- 支撑运营按标签与行为圈选人群，提升精准营销效率；
- 建立可配置的会员等级与成长值体系，驱动复购与活跃；
- 统一积分规则，为抵现 / 兑换 / 消费送分提供可运营配置。

**产品目标**
- 完成 MDM 端「会员360 + 会员体系 + 积分管理」信息架构与核心页面；
- 提供可复用的「筛选人群」组件，供会员分群、批量打标签共用；
- C 端可查看当前等级、权益、成长值明细与规则说明，并支持签到获成长值。

### 1.3 范围说明

**本期包含**
- 顶栏「会员」菜单与侧栏分组（会员360 / 会员体系 / 积分管理）
- 会员标签 CRUD、关联用户跳转
- 批量打标签（任务列表 / 新建编辑 / 人群列表）
- 会员分群（列表 / 人群列表）与 CRM 筛选人群弹窗
- 会员等级（列表 / 新增编辑页）、成长值规则、成长值明细、规则说明
- 积分规则、积分明细
- C 端：我的入口 → 会员中心 → 成长值明细 / 规则说明 / 每日签到

**本期不包含**
- 真实后端接口与权限体系落地（原型为本地演示数据）
- 「参与活动」筛选字段正式可用（原型标注待开发）
- 营销-积分商城商品配置页改造（积分兑换商品规则仅提示前往该处配置）
- 积分 / 成长值与订单、售后系统的正式对账链路（仅原型规则与明细展示）

## 二、用户分析

### 2.1 目标用户

| 角色 | 特征 | 使用场景 | 现有行为 |
|------|------|----------|----------|
| 会员运营 | 熟悉 MDM，负责标签、分群、等级与积分策略 | 配置规则、圈人、批量打标、查看明细 | 人工导出 / 线下表格 |
| 客服 / 会员管理员 | 需查会员等级、成长值、积分流水并手工调整 | 查询明细、手工增减成长值/积分 | 依赖订单或财务侧查数 |
| C 端会员 | 消费 / 签到 / 浏览等活跃用户 | 查看等级权益、成长进度、规则说明 | 仅能在「我的」看到静态等级文案 |

### 2.2 用户痛点

| # | 痛点 | 描述 | 影响程度 |
|---|------|------|----------|
| 1 | 圈人能力弱 | 无法按标签、消费、行动、偏好组合筛选 | 高 |
| 2 | 等级不可运营 | 等级权益、成长值获取方式无法后台配置 | 高 |
| 3 | 打标效率低 | 缺少批量打标与自动更新机制 | 中 |
| 4 | C 端感知弱 | 用户不清楚如何获得成长值及当前权益 | 中 |
| 5 | 积分规则分散 | 抵现 / 兑换 / 消费送分缺少统一配置与流水 | 高 |

### 2.3 用户旅程（核心路径）

**运营配置等级 → C 端感知**
1. 运营配置成长值规则与会员等级权益  
2. 编辑规则说明文档并发布  
3. C 端用户在「我的」点击等级 → 会员中心查看权益与获取成长值入口  
4. 用户签到 / 下单等行为产生成长值 → 次日在成长值明细可见  

**运营圈人打标**
1. 维护会员标签组与标签值  
2. 新建批量打标签任务 → 选择打标方式 / 标签值处理 / 筛选人群  
3. 手动任务启用后可点「更新」；自动任务每日凌晨更新  
4. 查看任务覆盖人数与人群列表，必要时导出

### 3.1 会员标签

**模块说明**：维护标签组与标签值，支撑分群与批量打标。

#### FR-TAG-001 会员标签列表与 CRUD

**优先级**：P0  
**描述**：提供会员标签列表页（样式对齐会员管理）。支持按标签值、标签组、标签组规则、状态筛选；新增/编辑标签组（含多个标签值）；启用/禁用/删除；查看关联用户数。

**字段要点**：
- 标签组名称（最长 50）、标签组规则、标签值（每项最长 50）
- 列表展示：序号、标签值、标签组、标签组规则、关联用户数、创建时间、状态、操作

**验收标准**：
- [ ] 支持新增、编辑、启用、禁用、删除
- [ ] 有关联用户的标签不可删除；编辑时不可移除已有关联的标签值
- [ ] 「查看关联用户」跳转会员管理并携带该标签作为筛选条件
- [ ] 「新增标签」「批量打标签」按钮位于查询旁，高度/风格与查询按钮一致（描边样式）

**异常情况**：删除有关联用户的标签时提示不可删。

#### FR-TAG-002 标签组规则枚举

**优先级**：P0  

| 枚举 | 取值 |
|------|------|
| 标签组规则 | 单选、多选 |
| 状态 | 启用、禁用 |

### 3.2 批量打标签

**模块说明**：按筛选条件对人群批量打标，支持手动/自动更新。

#### FR-BATCH-001 批量打标签任务列表

**优先级**：P0  
**描述**：独立菜单「批量打标签」。列表筛选：标签值、打标方式、状态。支持编辑、查看/修改筛选条件、更新（手动且启用时）、切换手动/自动、启停用；人数可下钻人群列表。

**验收标准**：
- [ ] 会员标签页「批量打标签」跳转新建页并自动打开新建流程
- [ ] 打标方式为手动且状态为启用时展示「更新」按钮
- [ ] 修改筛选条件需二次确认；确认后按新条件更新人群
- [ ] 人数链接进入人群列表；支持导出

#### FR-BATCH-002 新建/编辑批量打标签

**优先级**：P0  
**描述**：配置打标方式、标签值处理方式、选择标签、选择人群（复用筛选人群弹窗）。

| 配置项 | 取值 / 规则 |
|--------|-------------|
| 打标方式 | 手动、自动（悬停提示：手动需用户点击更新才触发；自动为系统每天凌晨开始更新） |
| 标签值处理 | 覆盖、添加；同一标签组内单选标签只支持覆盖 |
| 条件关系 | 且、或 |
| 任务状态 | 启用、停用 |

**验收标准**：
- [ ] 选择单选标签组时，标签值处理锁定为覆盖
- [ ] 可打开筛选人群弹窗配置条件并预估人数
- [ ] 保存后进入任务列表；可查看对应人群列表（样式同会员分群人群列表）

### 3.3 会员分群与筛选人群

**模块说明**：CRM 人群分组能力；筛选弹窗为跨模块组件。

#### FR-SEG-001 会员分群列表

**优先级**：P0  
**描述**：列表展示人群名称、条件关系、筛选规则、人数、更新方式、创建人、创建时间、更新时间、状态、操作。新建分群按钮在查询旁。

| 配置项 | 取值 |
|--------|------|
| 更新方式 | 手动、自动（提示同批量打标） |
| 状态 | 启用、停用 |

**验收标准**：
- [ ] 支持新建（先填人群名称，最长 40 → 再配筛选条件）、重命名、编辑筛选条件（需确认）、启停用、切换更新方式
- [ ] 手动且启用时展示「更新」
- [ ] 人数下钻人群列表；支持按会员 ID/昵称/手机号、注册时间筛选；手机号中间位脱敏；昵称可点进会员详情；支持导出
- [ ] 注册时间起止支持清空

#### FR-SEG-002 筛选人群弹窗（CrmAudienceFilter）

**优先级**：P0  
**描述**：左侧分类 + 右侧条件配置，支持且/或关系，预估人数。被会员分群、批量打标签调用。

**条件分类**

| 分类 | 说明 |
|------|------|
| 基础资料 | 性别、年龄、注册时间、会员等级、成长值、所在地区、绑定门店、会员来源 |
| 会员标签 | 按标签组/标签值圈选 |
| 消费 | 累计消费/售后、客单价、首次/最近消费、购买/加购商品等 |
| 行动 | 直播观看、浏览未下单、加购未支付、领券未使用、最近登录、参与活动（待开发） |
| 偏好 | 浏览类目、价格带、渠道、浏览/购买时段偏好 |

**数值运算符**：大于等于、小于等于、等于、介于  

**标签匹配**：包含任意、包含全部、不包含  

**验收标准**：
- [ ] 五类条件均可增删；已选条件展示在列表中
- [ ] 地区选择为省市区；门店支持搜索多选；选择弹层高度不超过筛选弹窗
- [ ] 「浏览未下单」「加购未支付」支持次数、距今时长（天）
- [ ] 消费侧支持：首次消费、购买商品、加购商品、最近一笔消费等组合条件（时间 / 金额 / 件数 / 指定商品或类目）
- [ ] 「参与活动」展示为待开发、不可配置

**关键字段提示文案（需与原型一致）**
- 累计消费金额：为累计支付成功金额，不扣除售后金额
- 累计消费次数：为累计支付成功订单数，不扣除售后订单数
- 累计售后金额：为售后完成的实退金额
- 累计售后次数：为售后完成的次数
- 客单价：为累计消费金额 / 累计消费次数
- 最近观看直播未下单：为最近有支付时间的观看直播数据
- 浏览未下单：以最近有支付时间的第一笔浏览商品详情记录为起始时间
- 加购未支付：以最近有支付时间的第一笔加购记录为起始时间
- 浏览商品类目：为浏览商品所属的类目
- 浏览价格带偏好：为浏览商品时的价格，多规格取最低价格

### 3.4 会员等级与成长值

**模块说明**：配置最多 15 个等级及权益；成长值驱动升降级；提供明细与对外规则说明。

#### FR-LVL-001 会员等级列表

**优先级**：P0  
**描述**：列表按成长值从低到高排列。展示等级图标、名称、成长值、权益摘要、会员人数、更新时间、状态。支持新增、编辑、启停用、删除。

**规则说明（页面提示）**：
- 最多可设置 15 个等级
- 成长值为 0 的等级为默认等级：不可删除、不可禁用、不可修改成长值；列表展示「默认」标识
- 升级：满足成长值立即生效；降级：每日统一处理

**验收标准**：
- [ ] 最多 15 个等级；超出不可新增
- [ ] 默认等级不可禁用/删除/改成长值；禁止禁用按钮对默认等级不展示
- [ ] 会员人数可跳转会员管理并筛选该等级
- [ ] 「新增等级」「规则说明」按钮在查询旁，样式同查询（描边）
- [ ] 规则说明入口悬停提示：此处规则说明将在用户端展示

#### FR-LVL-002 新增/编辑会员等级（独立页面）

**优先级**：P0  
**描述**：页面化配置基础信息与会员权益；每项权益有独立开关与说明文案（说明非必填，支持换行）。

**基础信息**：等级名称（最长 20）、等级图标（JPG/PNG/WEBP/SVG，≤2MB）、成长值（非负整数；新增不可为 0）

**会员权益**

| 权益 | 配置项 |
|------|--------|
| 赠送积分 | 积分数 |
| 赠送券 | 发放模式 + 优惠券列表（名称、张数） |
| 商品会员折扣 | 折扣 %（1–100）+ 适用范围 |
| 积分等级赠送比例 | ≥100 的整数 % |
| 生日送券 | 发放模式 + 优惠券列表 |

**发放模式**：累计赠送、每月赠送、每日赠送  

**折扣适用范围**：全部商品、适用商品、适用类目、排除商品、排除类目  

**交互**：
- 选择优惠券：弹窗同「会员管理-发放优惠券」；列表展示优惠券名称、面额、门槛、有效期、领取规则、剩余库存；用尽/过期券不展示；勾选即可，无需券名前缀勾选样式；单行展示不换行
- 选择商品：支持类目、商品名称、SKU 编码筛选；列表展示图片、名称、SKU 编码、价格（多 SKU 为价格区间）
- 适用范围为「全部商品」时不展示「选择类目」按钮

**验收标准**：
- [ ] 各权益开关关闭时对应配置不可编辑
- [ ] 名称、成长值唯一性校验通过后方可保存
- [ ] 默认等级仅允许改名称/图标/权益，不可改成长值

#### FR-LVL-003 成长值规则

**优先级**：P0  
**描述**：配置成长值有效期、消费获成长值、活跃获成长值。升降级策略为固定说明文案（满足成长值升级，不满足则降级）。

| 配置项 | 取值 / 规则 |
|--------|-------------|
| 有效期类型 | 永久有效、滚动有效期 |
| 滚动天数 | 有效天数（默认 365） |
| 消费获成长值 | 开关；每支付 X 元获得 Y 成长值；售后成功按获取时比例扣减 |
| 活跃获成长值 | 开关；行为：每日签到、浏览商品、分享邀请、评价订单；每行可配置启用、每次获得值、每日上限（0=不限制） |

**验收标准**：
- [ ] 有效期类型为永久时，文案说明永久有效；滚动时说明自获取日起 N 天内有效，每日 0 点统一过期处理
- [ ] 消费/活跃子项受总开关控制

#### FR-LVL-004 成长值明细

**优先级**：P0  
**描述**：查询会员成长值流水，支持手工调整。

**筛选**：会员（ID/昵称/手机号）、获取时间（起止，可清空）、获取方式、明细类型（随获取方式联动）、状态  

**列表字段**：流水号、会员ID、昵称、手机号、获取方式、明细类型、变动成长值、关联单号、备注、获取时间、过期时间、状态、操作人、操作  

| 维度 | 取值 |
|------|------|
| 获取方式 | 购物消费、用户活跃、手工调整 |
| 明细类型-消费 | 订单完成、售后完成 |
| 明细类型-活跃 | 每日签到、浏览商品、分享邀请、评价订单 |
| 明细类型-手工 | 手工增加、手工减少 |
| 状态 | 有效、过期 |

**规则**：
- 有效状态由「获取时间 + 成长值规则有效期」计算；过期展示过期时间，有效可不展示过期时间或按规则展示
- 手工调整无过期时间时展示 `--`
- 手工减少时扣减量不可大于会员剩余成长值
- 手工操作记录操作人

## 五、方案设计

### 5.1 页面结构

```
顶栏「会员」
├── 会员360
│   ├── 会员管理（原 C 端会员）
│   ├── 会员标签
│   ├── 批量打标签 → 新建/编辑表单 → 人群列表
│   └── 会员分群 → 人群列表
├── 会员体系
│   ├── 会员等级 → 新增/编辑页
│   ├── 成长值规则
│   ├── 成长值明细
│   └── 规则说明
└── 积分管理
    ├── 积分规则
    └── 积分明细

C 端
我的 → 会员中心 → 成长值明细 / 规则说明 / 签到
```

### 5.2 核心交互流程

**批量打标（手动）**  
选择标签与人群 → 保存并启用 → 点击「更新」→ 系统按条件打标 → 人数/人群列表刷新  

**批量打标（自动）**  
配置自动更新 → 每日凌晨系统更新 → 列表更新时间刷新  

**等级升降级**  
成长值变动 → 满足更高成长值立即升级 → 不满足当前等级门槛则每日统一降级
