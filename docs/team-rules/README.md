# 团队规则（Team Rules）

本目录存放 **产品 / 业务 / 原型协作** 由你与团队共同制定的规则，供同事查阅，并供 Cursor Agent 对齐实现。

## 位置

```
d:\1zz文件\07 冷丰\cursor原型\LFerp\docs\team-rules\
```

相对仓库根目录：`docs/team-rules/`

## 约定

| 字段 | 说明 |
|------|------|
| 规则名称 | 文件标题 / 文首「规则名称」 |
| 规则制定人 | 提出或拍板该规则的人（可多人，用顿号分隔） |
| 制定日期 | `YYYY-MM-DD` |
| 适用范围 | 哪些页面 / 模块生效 |

- 新增规则：复制 `_模板.md`，改名并填写元信息与正文。
- 本目录给人看；Cursor 自动执行的镜像在 `.cursor/rules/`（`.mdc`），文内会注明对应的团队规则文件。
- 规则冲突时，以本目录最新版本为准，再同步更新 `.mdc`。
