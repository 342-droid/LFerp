## 0. 文案透出分层（门店可见 vs 内部）

门店端页面上出现的字，一律按「经营者能不能读懂、该不该看见」筛一遍。

| 层级 | 谁看 | 放哪里 | 写法 |
|---|---|---|---|
| **A · 门店透出** | 门店老板／店长 | 页内说明、问号 Sheet、指标名、空态、按钮 | 白话：说「是什么／怎么算／别和什么混」；禁止内部词 |
| **B · 内部口径** | 产品／研发／财务／知页 | `03`／`04`／本文件参数表、代码注释 | 可用：口径、SKU、清分、代收待转、待知页、Q-xx、临时 |
| **C · 原型元信息** | 仅验收同学 | URL 参数、本地 README、对话 | 如 `?rbt=0`、演示数据说明；**禁止写进门店页正文** |

**禁止出现在门店透出文案（A）中的词／句式**

- 口径、知页、临时、待确认、待替换、分栏（产品黑话）、时点值  
- SKU、清分最小单位、代收待转、仅 PC 可见、异常订单映射  
- 完整口径见××分析、与平台××同一口径、本店视角复活（可改成「再次在本店消费后不再计流失」）  
- 「演示」「样例数据」「验收开关」等原型自述（除非单独验收面板）

**可以透出（A）的内容**

- 指标中文名与单位：营业额、待结佣金、约定付款、付款中…  
- 时间语义：按支付成功／按入账／当前进度、数据截至…  
- 防误读：佣金与营业额不是同一笔钱，请勿相加  
- 问号里的白话公式：复购率＝…÷…（公式可透出；「临时待知页」不可透出）

**双写约定**：同一规则在 A 用白话、在 B 用精确口径；改口径先改 `03`／`04`，再改门店问号文案。

## 1. 视觉样式（沿用现网经营参谋）

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#ff6501` / `#fd6020` | Tab 激活、主按钮、橙卡 |
| 页背景 | `#f6f7fb` + 顶部暖橙渐变 | 壳层 |
| 卡片 | `#fff`，圆角约 12px，轻分隔 | 各区块 |
| 主文案 | `#1f2024` | 标题、数值 |
| 辅助 | `#71727a` | 口径、环比、说明 |
| 涨／跌 | `#f62b57` / `#45c74a` | 环比箭头色（涨红跌绿，沿用现网） |
| 数字字体 | DIN Alternate 优先 | 大数字 |
| 布局 | 手机竖屏；底栏 4 Tab；内容区可滚动 | H5 |

**呈现硬规则**

1. **佣金**与**经营数据**分两区；会员进经营区「顾客分析」，不进佣金橙卡。  
2. 区说明只放问号；「数据截至」放经营区标题右侧；页内不常驻长说明。  
3. 卡片与卡片间距 **10px**。  
4. 营业额门店说明＝**顾客实际支付金额**（内部精确拆运费仍见 03／04）。  
5. 佣金按入账／待结；经营按支付成功；周期 chips **只改经营区**。  
6. **RBT** 卡：有业务才出；卡内「查看每日还款」。  
7. 自定义对齐 C 端钱包起止样式；底栏沿用现网。

## 2. 页面结构（单店 · 总览）

```text
┌─────────────────────────────────────┐
│ [总览]  佣金明细                     │  ← 顶 Tab
├─────────────────────────────────────┤
│ ██ 橙卡三格 ██                       │  ← 仅佣金
│ 待结佣金 │ 本月佣金 │ 年度佣金       │
├─────────────────────────────────────┤
│ 经营数据                    数据截至 │
│ (今天)(昨天)(近七天)(本月)(自定义)   │
├─────────────────────────────────────┤
│ ▌经营概览                    [今天] │
│  营业额 │ 订单数 │ 核销数 │ 客单价  │
├─────────────────────────────────────┤
│ ▌经营趋势  [营业额|订单|新客|核销]  │
├─────────────────────────────────────┤
│ ▌顾客分析                 [近30天]  │
│  会员数 · 新客／老客 · 复购／流失    │
├─────────────────────────────────────┤
│ ▌RBT（有业务才出）· 查看每日还款 ›  │
├─────────────────────────────────────┤
│ ▌进货概况 ›                          │
└─────────────────────────────────────┘
│ 工作台 │ AI │ 经营参谋 │ 更多        │
```

**目标菜单（相对现网增量，见 01§6.4）**

| 入口 | 现网 | 目标 |
|---|---|---|
| 总览 | ✅ | 保留；补联营摘要卡（有「还款中」业务时） |
| 佣金明细 | ✅ | 保留；下单日／入账日切换不变 |
| 进货概况 | ✅ | 保留＝普通进货 |
| 联营采购 | △ 待补 | 与普通进货**分开**；看本店扣费／回收明细 |
| 扣费与结算 | △ 可并入联营／佣金 | 应扣／实扣差异入口（超阈可红点，见预警） |

## 3. 筛选与全局参数

| 参数 ID | 界面 | 取值 | 作用范围 | 说明 |
|---|---|---|---|---|
| `storeId` | 隐式 | 当前登录门店 | 全页 | 单店端固定本店；不可切他店 |
| `range` | Chips | `today` / `yesterday` / `7d` / `month` / `custom` | 经营概览、趋势、进货等**经营指标** | 即「计算周期」（Q-SET-06） |
| `customStart` / `customEnd` | 自定义日期 | 自然日 | 仅 `range=custom` | 含首尾日 |
| `custWindow` | 顾客卡右侧 | 默认 `30d` | 仅顾客分析块 | 复购／新老客窗口；流失判定另用 30 天无交易（Q-CUST-02） |
| `asOf` | 页头「数据截至」 | 服务端时间戳 | 展示 | 近实时专题用；钱包余额旁可写「实时」 |
| `trendMetric` | 趋势分段 | `paid` / `orders` / `newCustomers` / `verify` | 仅趋势图 | 切换序列，不改 `range` |

**不受 `range` 影响的参数／指标**

| 参数／指标 | 原因 |
|---|---|
| 待结佣金、可提现余额 | 当前资金状态，不随历史经营日切换 |
| 会员数 | 放在顾客分析；现网为存量；若改「期末会员」需另发口径 |
| 联营「剩余应回收」 | 时点值（约定快照 − 净累计实扣），可另提供「本期实扣」随 `range` |

## 4. 区块与指标参数说明

### 4.1 橙卡快照（资金／会员向）

| 展示名 | 参数／指标 ID | 事件时间 | 口径摘要 | 备注 |
|---|---|---|---|---|
| 待结佣金 | `COMM_PENDING` | 当前状态 | 已入待结、未入账成功 | 点按下钻佣金明细·待结 |
| 本月佣金 | `COMM_MONTH` | 入账成功月 | 自然月已入账佣金 | 与经营「本月营业额」分栏 |
| 年度佣金 | `COMM_YEAR` | 入账成功年 | 自然年已入账 | |
| 会员数 | `MEMBER_CNT` | 存量 | 本店绑定／有成交会员（现网） | 与支付人数区分 |

门店所得**仅佣金**，无非佣金收入（Q-REV-02）。

### 4.2 经营概览（经营向 · 随 `range`）

| 展示名 | 参数／指标 ID | 事件时间 | 口径摘要 | 下钻 |
|---|---|---|---|---|
| 营业额 | `PAY_GMV`（本店） | 支付成功 | 本店支付成功金额；含 POS 等已确认渠道 | 订单／商品 |
| 订单数 | `ORDER_CNT` | 支付成功 | 主单或子单口径与现网参谋一致，拆单规则跟知页 | 订单列表 |
| 核销数 | `FUL_VERIFY` | 核销时间 | ＝公司自提核销量（Q-FUL-04）；一期按**子订单** | 核销明细 |
| 客单价 | `AOV` | 派生 | 营业额 ÷ 支付人数（或订单数，与现网一致并在 ? 说明） | — |

环比脚注：相对上一同等长度周期（今天→昨天；本月→上月等）。

### 4.3 经营趋势

| 参数 | 说明 |
|---|---|
| X 轴 | 随 `range`：小时／日 |
| Y 轴 | 由 `trendMetric` 决定 |
| 空态 | 无点时「暂未获取」或真 0 显示 `0`（Q-DATA-04） |

### 4.4 顾客分析

| 展示名 | 参数／指标 ID | 口径摘要 | 标注 |
|---|---|---|---|
| 新客下单 | `NEW_BUYERS` | 首次在**本店**支付成功 | 他店购买不影响 |
| 老客下单 | `OLD_BUYERS` | 非新客的本期支付顾客 | 新+老＝支付人数 |
| 复购人数 | `REPURCHASE_USERS` | 本期支付顾客中历史本店支付 ≥2 次 | **临时口径 · 待知页替换** |
| 复购率 | `REPURCHASE_RATE` | 复购人数 ÷ 本期支付人数 | 同上 |
| 流失会员 | `LOST_MEMBERS` | 连续 **30** 天无交易；本店视角复活＝**本店**再交易 | Q-CUST-02 门店维 |
| 有成交天数 | `ACTIVE_DAYS` | 有支付成功成交的自然日数；**不计**仅退款日／仅进货日 | 可放次级信息或详情 |

顾客块默认窗 `custWindow=30d`，与流失 30 天对齐展示，但复购分母仍是窗内支付人数。

### 4.5 RBT 摘要（有有效 RBT 业务才展示）

| 界面文案 | 原文档名 | 指标 ID | 口径摘要 |
|---|---|---|---|
| **RBT**（区块名） | 联营回收 | — | 门店端对外名；有业务才出卡 |
| 约定付款 | 约定回收 | `JV_AGREED_RECOUP` | 门店应收快照 |
| 累计实付 | 累计实扣 | `JV_ACTUAL_DEDUCT` | 成功日结扣费合计 |
| 剩余应付 | 剩余应回收 | `JV_REMAIN` | 约定付款 − 累计实付 |
| 付款中 | 还款中 | 状态 | 业务进行中、按日付款 |
| 预计回本周期 | — | `JV_FORECAST_CYCLE` | 跟回本分析 v3；**要展示** |
| 当前 | 原「时点」 | — | 表示本卡是**此刻进度**，不随经营周期 chips 切换 |

**已删的内部说明**：不再在卡底写「与营业额／佣金分栏 · 点按进日结明细」。改为按钮文案「查看日结明细 ›」进入 `biz-rbt.html`。

### 4.6 进货概况入口

普通进货支付／退款／商品排行；**不与**联营采购混在同一「进货」总数。

## 5. 交互与说明组件

| 元素 | 行为 |
|---|---|
| `?` 帮助 | 底部 Sheet 展示**门店白话**说明（A 层）；精确口径只在本节参数表（B 层） |
| 指标格点击 | 下钻订单／佣金／联营明细 |
| 预警红点 | 本店命中 AL-01／02／04／08 等时，在对应入口角标；列表在独立「经营提醒」，**不回写**改数（Q-AL-09） |
| 空态 | 未拉到：「暂未获取」；业务零：`0` |

## 6. 参数速查（给研发／测试）

| 参数 | 类型 | 默认 | 必填 | 校验 |
|---|---|---|---|---|
| `storeId` | string | 登录门店 | 是 | 本店权限 |
| `range` | enum | `today` | 是 | 枚举内 |
| `customStart` | date | — | `custom` 时 | ≤ End；不超过今天 |
| `customEnd` | date | — | `custom` 时 | ≥ Start |
| `custWindow` | enum | `30d` | 否 | 一期固定 30d 亦可 |
| `trendMetric` | enum | `paid` | 否 | |
| `asOf` | datetime | 服务端 | 只读 | 页头展示 |

**事件时间对照（单店页）**

| 区块 | 默认事件 |
|---|---|
| 经营概览／趋势／营业额 | 支付成功 |
| 核销数 | 核销时间 |
| 佣金入账类 | 佣金入账成功（现网五态） |
| 待结／余额 | 当前状态 |
| 联营实扣 | 扣费成功日 |
| 顾客支付人数／复购 | 支付成功 |
| 流失 | 最后支付成功日距今 |

## 7. 与平台「单店下钻」的差异

| 项 | 门店端本店 | ERP／财务／BD 下钻单店 |
|---|---|---|
| 门店选择 | 固定本店 | 可选门店（授权范围内） |
| 导出 | 不可（仅财务可导出） | 财务可导出 |
| 联营回本周期 v3 | **门店端展示**（白话估算说明） | 内部可看完整测算口径 |
| 测试店 | 本店若是测试店仍可见自己 | 驾驶舱默认剔除测试店 |
| 菜单 | 经营参谋 H5 | ERP 门店经营 · 单店分析 |
