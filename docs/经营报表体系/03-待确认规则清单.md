## 使用说明

- 每条可单独进评审；编号稳定；结论回写指标字典时，**已确认与暂缓分项书写**，禁止整项统标为「已确认」或「暂缓」。
- **评审状态**：`已确认` / `部分确认` / `暂缓` / `待拍`。
- **依赖方**：业务 / 财务 / 产品 / 数据 / 研发（可多选）。
- 确认前原型可用占位或沿用现网演示值；正式口径以本清单已确认段 + 知页现网为准。

### RBT 状态机对齐（知页《6-需求单管理PRD》V1.3）

报表筛选与权限跟随现有业务，**不照搬旧提示语**（如「支付中」「撤回后回待接单」等）：

| 类型 | 状态 |
|---|---|
| 主链路 | 待审核 → 待接单 → 待确认签约 → 待签署 → **待付款** → 待复核 → **还款中** → 已完成 |
| 旁路 | **待重新确认**（待确认签约撤回接单；不直接回待接单）· 已作废 · 已驳回 |
| 语义 | 待付款＝等贸易商付款；还款中＝门店按日还款 |
| 历史别名 | 支付中／待还款 → 还款中；待支付 → 待付款（仅迁移） |

### A1｜Q-JV-01｜`RBT_DEMAND_AMT`

**已确认**

- 按需求**提交成功时间**统计，只统计提交成功的需求。
- 需求相关金额**不代表已成交**，任何看板**不能替代 GMV**。
- 展示须区分需求单的 **商品金额、服务费、总金额**，禁止混用同名展示字段。
- 需求单无独立含税／运费字段 → **本期不假设含税、不把运费计入**本指标；只使用上述三分列。

**暂缓**

- 三分列对应的具体落库字段名（→ P3b）。

### A2｜Q-JV-02｜`TRADER_RECEIVABLE`

**已确认**

- 取对应需求单的贸易商应收记录；现有计算为 **商品金额 × 贸易商结算系数**（与知页需求单管理一致）。
- 不直接等同于合同金额、实际投入、已结算金额或实际到账。
- 与 GMV、公司收入强制分列，不能直接相加。
- **结算系数与日常扣费比例是不同概念**。

**暂缓**

- 与合同、结算单的具体字段映射。

### A3｜Q-JV-03｜`JV_INVEST`

**已确认**

- 按投入主体及对应 RBT、商城／采购业务的**实际发生记录**认定，不另设「约定投入价」。
- **贸易商投入**：关联贸易商向冷丰供应链采购的上游交易及实际付款。供应链采购单按**商品原始售价**计价，金额等于需求**商品金额**；不能用门店结算系数放大后的回收金额代替投入。
- **公司投入**：关联正常采购体系中向真实供应商采购的单据及实际付款；与贸易商投入分别统计；同一批货不同交易环节金额不能直接相加。
- **商城／普通采购**：沿用订单已有实付构成，货款、运费、优惠分别追溯；混合支付取完整实付，不能只取钱包扣款。
- 需求发布、接单、合同生成**不直接**认定为实际投入。同一投入不能因付款、采购及交付记录分别存在而重复累计。
- 模拟支付、确认线下支付及采购单自动完成状态，**不能单独**证明真实资金已投入。

**暂缓**

- 实际付款金额字段、成功事件及未明确费用项。尤其：贸易商端「总金额」展示为贸易商应收，上游供应链采购按原始售价；**不能未经核准将贸易商应收作为实际投入**。

### A4｜Q-JV-04｜`JV_AGREED_RECOUP`

**已确认**（2026-11-16）

- **口径（RBT）**：约定回收按**门店应收**认定——**商品金额 × 门店结算系数**（与知页门店采购售价一致）。日结应扣仍按「营业流水 × 结算比例」（见 Q-JV-05），二者勿混；**不以**贸易商应收、需求总金额替代约定回收。
- 合同／需求单上可无独立字段名「约定回收总额」；报表映射到上述门店应收金额。
- **生效时点**：需求单**审核通过后**固化快照（对齐知页初审通过，离开「待审核」）；此前不计入本指标。
- **历史与改比例**：已出历史报表用快照、**不重算**；改比例只影响日后应扣，**不默认**用当前合同／当前比例覆盖历史。比例付无「固定期数总额」时，仍以该快照为剩余应回收的分母。

### A5｜Q-JV-05｜`JV_SHOULD_DEDUCT`

**已确认**

- 沿用对应 RBT 需求单的现有结算规则，**不另建统一比例**。
- 周期及方式：当前为 **日结＋比例付**；不将需求总额平均拆成固定每日还款额。
- 适用对象：具体需求单、需求门店及对应联营业务。
- 比例来源：初审通过时按渠道维护默认比例及商品类目比例，保存到需求单；后续修改沿用现有规则。
- 当前原型渠道为直播、商城。同一渠道内优先已配置类目比例，否则该渠道默认比例，**两者不叠加**；渠道之间不交叉套用。
- 现有日明细原型按「当日该渠道营业流水 × 对应比例」演示；正式指标对齐实际结算基数，**不直接**将所有渠道统一按 GMV 计算。
- 门店／贸易商／服务商**结算系数**用于约定金额及各方应收，**不作为**每日扣费比例。
- 应扣是规则计算结果，**不能替代**实扣或实际回收。
- 同店多笔「还款中」有效需求：各单按自身结算比例**分别**乘当日该渠道营业流水后，若合计比例＞100%则**归一化到 100%**；不得自造优先级。
- 累计实扣净额对剩余的扣减以约定回收快照为**封顶**（不超过 Q-JV-04 快照）。
- 改比例只影响日后应扣（见 Q-JV-04）。

**暂缓**

- 退款、运费、佣金型业务对营业流水基数的影响（**二期**）；流水字段映射（→ P3b）。

### A6｜Q-JV-06｜`JV_ACTUAL_DEDUCT`

**已确认**

- 以实际成功执行的扣费记录为依据，不取应扣测算值。
- 失败金额不计入成功实扣。
- 部分成功仅计已确认成功部分。

**暂缓**

- 成功状态、流水来源、关联键及重复记录识别规则。

### A7｜Q-JV-07｜`JV_ACTUAL_RECOUP`

**已确认**

- **实扣等于实际回收**，两项使用同一成功扣费数据口径。
- 可按报表语义分别展示，但不能作为两笔金额重复累计。
- 扣费回退及冲正的影响见 Q-JV-11（已确认）。

### A8｜Q-JV-08｜`JV_REMAIN`

**已确认**（2026-11-16）

- 基础公式：**约定回收总额 − 累计实际回收金额**。
- 累计实际回收金额＝累计实扣金额（成功回退／冲正后的净累计，见 Q-JV-11）。
- 约定回收总额取 Q-JV-04 快照；成功回退／冲正**增加**剩余应回收（不重复扣减）。
- **减免／坏账**：须有财务成功减免／坏账流水才减少剩余；**不默认**无流水自动减剩余（对齐 Q-JV-11「有流水才认」）。

### A9｜Q-JV-09｜`JV_FORECAST_CYCLE`

**已确认**（2026-11-16）

- 仅用于预测和预警，不是固定还款期或合同到期日。
- 展示预测基准时间及计算依据。
- 数据不足或无法形成有效预测时，不生成预计日期。
- **测算模型**：按运营《门店回本分析》规范 **v3**（与 Q-JV-10 同一套）——门店回本周期、公司回本周期、累计分佣天数（不加 1）、日均分佣＝分佣÷天数、投入÷日均分佣等；单位＝天；投入或分佣为 0 时输出「无法计算」／「不适用」。
- 刷新：随经营看板所选计算周期／取数日重算。
- 联营资金回收侧若另需「剩余÷日均实扣」预计天数，二期可单列，**本期以门店回本分析表为准**。

### A10｜Q-JV-10｜资金回收与经营回本

**已确认**

- 分别命名为「**联营资金回收**」和「**门店经营回本**」，分区展示，不共用「回本状态」。
- 贸易商查看本人联营业务的资金回收；内部人员按权限查看。
- 门店查看与本店相关的联营采购及扣费记录。
- **门店经营回本公式**对齐运营《门店回本分析》规范 **v3**（样例：阳光水岸店取数表，2026-09-25）。与 RBT 联营约定回收／日结扣费**不是同一套指标**。

核心口径（v3）：

| 项 | 口径 |
|---|---|
| 统计周期 | 该店最早一笔订单日 → 统计日；累计分佣天数＝`DATEDIFF(今天, 最早下单日)`（**不加 1**） |
| 收入订单 | `status <> CANCELED`（含待支付） |
| 净订单 | 收入订单剔除拉新标签行与奖品／积分行后仍有剩余行的订单 |
| 公司投入 | **拉新投入**＋**锁客投入**。拉新＝交易成功且 `acquire_type=SALE` 且命中 MDM 标签 `PULL_NEW_PRODUCT` 的去重订单 × 拉新单客成本；锁客＝交易成功且 `acquire_type ∈ (LUCKY_BAG_PRIZE, SIGN_IN_PRIZE, WATCH_REWARD_PRIZE)` 的行采购成本合计（积分兑换不算） |
| 公司分佣 | 收入订单清分中 `payee_type ∉ (STORE, MERCHANT, SUPPLIER)` |
| 门店分佣 | 收入订单清分中 `payee_type ∈ (STORE, MERCHANT)` |
| 门店回本周期 | 日均门店分佣＝门店分佣÷累计分佣天数；若门店分佣＞门店投入则报已分佣与天数，否则 **门店投入 ÷ 日均门店分佣**；门店分佣或投入为 0 →「无法计算」／「不适用」 |
| 公司回本周期 | 日均公司分佣＝公司分佣÷累计分佣天数；公司投入为 0 →「不适用」（不输出「已回本」） |
| 筛选键 | 以 `store_id` 为唯一键；`store_name` 仅为下单快照，不作为筛选 |

**暂缓**

- 「门店投入」录入来源与默认值；本指标对门店端／贸易商端的**可见权限**（样表为内部运营分析）。

### A11｜Q-JV-11｜扣费回退／冲正

**已确认**（2026-11-16）

- **仅认成功回退／冲正流水**；无此类流水＝本期无调整。**不按**订单退款时间臆造回退。
- 成功回退／冲正 → **减少**累计实扣／实际回收，**相应增加**剩余应回收；**不删除、不覆盖**原成功扣费行，另记一笔关联原流水的逆向。
- 记账时点＝**冲正／回退成功日**；已出历史报表**不回溯覆盖**。

### A12｜Q-JV-12｜业务结束后历史明细

**已确认**（2026-11-16）

- 贸易商在该笔业务结束后，**不再**基于该笔业务持续查看门店经营数据；存在其他有效业务关系时，按其授权独立判断。
- 门店端保留并可查询与本店相关的全部合同、采购、扣费及结算明细，不因业务结束关闭查询。
- 扣费主体、扣费金额允许向本店展示。
- 不据此扩大其他角色的数据权限。
- 贸易商历史结算明细：**不限期可查看、不可导出**（与 Q-TR-01 一致）。
- **不保留**门店经营快照（业务结束后不再提供该笔业务下的门店经营数据浏览）。
