## 3. 指标与数据来源映射

| 驾驶舱指标 | 来源／事件 | 说明 |
|---|---|---|
| 支付 GMV | 消费者订单支付成功 | 含顾客实付运费；未扣退款；**不含** RBT／进货／佣金入账 |
| 退款金额 | 退款成功时间 | 含部分退、历史单本期退 |
| 净成交额 | 当期 GMV − 当期退款 | 可为负 |
| 支付主订单数 | 主订单去重 | 跨店仅本店归属金额 |
| 支付人数／客单价 | 支付成功聚合 | 分母 0 →「—」 |
| 有／无成交门店数 | 门店 × 支付成功 | 与档案启用态分列 |
| 财务确认收入 | 财务确认记录 | **确认日期**；≠GMV |
| 待发货／缺货 SKU 件数 | 履约／库存事实 | 主指标按 **SKU 件数** |
| 售后金额／售后率 | 售后单 | 率演示＝售后金额／GMV |
| 经营预警数量 | 预警规则 | 一期仅提示 |
| RBT 约定／实际／剩余回收 | 需求单结算规则 | 实扣＝实际回收；不入 GMV |
| 门店佣金 | 清分／入账 | 与 GMV 分列 |
| 供应商货款／结算／到账 | 结算单／钱包 | 已结算≠到账 |
| 贸易商应收／回收 | RBT 需求 | 关联门店 GMV ≠ 贸易商收入 |
| POS 全套 | — | **待接入**（不为 0） |
| 准时率正式值 | — | **规则待确认** |
| 直播触达／观看 | 外采 | **未获取** 时可显示 |

## 4. 已沿用的现有业务规则

1. 不改写交易、RBT 需求、结算、履约、售后及权限主链路。
2. 报表只做分析／汇总／筛选／下钻／权限展示。
3. 消费者 GMV、RBT 联营金额、财务确认收入、供应商货款、门店佣金、贸易商应收**强制分列**。
4. RBT 状态机与金额口径沿用知页／`02`／`03`／`04`（日结比例付、约定＝门店应收快照、实扣＝实际回收等）。
5. 门店佣金五态与清分按 SKU 商品实付；运费不参与分佣；平台补贴运费单列。
6. 顾客：普通运营仅汇总／脱敏；明细需角色＋组织＋字段级授权；导出另授。
7. 未接入／未获取展示「待接入」「未获取」，**禁止展示为 0**。
8. 页头展示统计时间、数据更新时间、口径说明。

## 5. 待确认规则清单（本驾驶舱标注）

与用户本次清单及 `03` 对齐，驾驶舱内已用「待接入／规则待确认／未获取」占位：

| 项 | 驾驶舱处理 |
|---|---|
| POS 接入时间／字段／堂食·外卖·核销映射 | POS 专题全量「待接入」 |
| 直播引流成交归因与防重复 | 直播／商城文案禁止交叉加总 |
| RBT 实际投入字段映射 | 投入指标「待接入」 |
| 实扣成功状态／关联键／重复扣费识别 | 部分演示；细表待确认 |
| 回退／冲正／减免／坏账对历史报表 | 影响项「待接入」 |
| 准时率承诺节点／例外／拆单聚合 | 准时率「规则待确认」 |
| 财务确认条件／确认记录／冲销 | 细则「待接入」 |
| 贸易商结束后历史结算查询范围 | 沿用 Q-JV-12；细表待产品 |
| 顾客明细权限矩阵 | 顾客专题权限条＋明细「待接入」 |
