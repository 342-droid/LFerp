### 研发交付差异（勿静默当成已对齐）

1. **客户订单页筛选能力**：历史 `store-orders.html` 仅支持履约状态 Tab（全部／待收货／待提货／已完成／排队中），**不支持**报表日期区间与商城／直播来源筛选。经营数据「查看全部订单」只传 `tab=全部` 与 `returnTo`（返回后保留经营筛选）；进入客户订单后列表范围与报表「当前筛选」**不一致**，界面不伪造成功携带日期／来源。
2. **进货订单页**：历史 `restock-orders.html` 数据来自进货商城订单存储，**不按**经营数据日期筛选过滤；返回通过 `returnTo` 回到经营进货 Tab。
3. **订单状态字段**：报表预览用演示数据的 `orderStatus`／`fulfillStatus`／`aftersaleStatus`；若真实接口缺履约状态，应显示「状态暂不可用」并在联调清单列出缺失字段，禁止用「— · 部分退款」代替履约状态。
4. **佣金明细 UI**：本轮不改已确认的佣金明细页交互，仅调整入口与分析页跳转参数。
