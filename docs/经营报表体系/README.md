## 阅读顺序建议

1. 先看 **01** 弄清「谁从哪进、看到哪一层」。
2. 再看 **02** 对已拍板指标（支付 GMV、净成交、佣金等）对齐口径。
3. 评审时用 **03** 逐条确认；拍板后改 **02** 状态列，避免口头口径漂移。
4. 清剩余项时直接看 **03「暂缓事项汇总」**（P3b 字段映射 → P4 SLA／细表）。
5. 业务复核已拍板口径用 **04**（流程图＋逻辑表）；改口径须回写 03／02。
