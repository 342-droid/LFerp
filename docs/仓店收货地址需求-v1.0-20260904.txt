## 1. 仓库档案 · 收货地址

仓库详情维护收货地址，交互与供应商一致：新增 / 编辑 / 设默认 / 删除。

- 按仓库编号存多条
- 必须有且仅有一条默认
- 无维护时，用仓库管理员、手机号、仓库位置生成一条默认地址

## 2. 售后退回到仓

配送订单的退货退款，审核区「仓库收货地址」只读仓库档案的默认收货地址。

按订单配送仓取值。页面不改，只换数据源。无地址时仍提示「暂未配置仓库收货地址」。

## 3. 门店档案 · 门店地址同步收货地址

新增 / 编辑门店时，把联系人、手机、省市区、详细地址同步成该门店的默认收货地址。

业务侧统一用 `getStoreReceiveInfo(门店ID或名称)` 取值。自提售后读这条地址。

页面和交互不变。

## 4. 售后寄回取值优先级

| 履约 | 读取 |
| --- | --- |
| 自提 | 门店收货地址 |
| 配送 | 仓库收货地址 |
| 快递 | 供应商收货地址（原逻辑） |
| 补货 | 不展示收货地址 |
